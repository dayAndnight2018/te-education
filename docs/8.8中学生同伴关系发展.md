# 8.8中学生同伴关系发展

同伴关系是指同龄人之间或者心理发展水平相当的个体之间交往过程中建立发展起来一种人际关系，分为:

**友谊**：是`两个个体之间`形成一种相互作用，较为持久稳定的双向关系，而非简单的喜爱和依恋

**同伴群体关系**: 儿童自发形成的具有共同目标，共同行为准则，相同兴趣，经常共同参加某些活动的群体关系，是指`两人以上`

### 中学生同伴关系的发展特点

1. 逐渐改变了团伙式的交往方式，进入中学以后，中学生的突出表现为心理上出现许多不安和焦躁，他们需要一个交流思想保守，秘密的地方，而团伙式的交往不具备这种功能，因此`中学生交往范围随着年龄增长而逐渐缩小`
2. `朋友关系日益重要，择友标准高`，他们认为朋友应该忠诚坦率，通情达理，关心体贴，保守秘密
3. `出现了异性友谊`，进入青春期以后，由于第二性征出现，使得男女同学之间出现了新的特点，双方开始意识到性别问题，并对异性产生了兴趣，表面上相互排斥，互不接近，逐渐的男女生之间开始融洽相处。

### 中学生同伴交往的技巧

1. 不要自我为中心
2. 学会倾听分享
3. 多参加集体活动
4. 理智把握交往的度
5. 学会拒绝大胆说不

### 中学生异性交往的指导

1. 培养健康的交往意识
2. 培养健康的交往态度
3. 培养正确的交往行为
4. 加强情感教育
5. 加强性教育
6. 正确应对恋爱现象。
