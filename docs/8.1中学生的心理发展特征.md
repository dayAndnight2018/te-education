# 8.1中学生的心理发展特征

个体发展的含义及其阶段心理发展是指个体从出生，成熟，衰老致死亡整个生命进程中所发生的一系列心理变化，各其心理发展分为8个阶段，乳儿期0-1岁，婴儿期1-3岁，幼儿或学龄前期3-6、7岁，童年期或学龄初期6、7岁到11、12岁，少年期或学龄中期为11、12-14、15岁，青年期为14、15-25岁，成年期是25岁到65岁，老年期是65岁以后。

### 个体心理发展的基本特征

阶段性与连续性：阶段性是指在心理发展过程中，当某些代表性的新特征量达到一定的程度之后，就会取代旧特征而处于主导地位，表现为阶段性的间断现象，而后一阶段的发展总是在前一阶段的基础上发生的，又萌发着下一阶段的新特征，表现出心理发展的连续性

顺序性与定向性：正常条件下，心理发展总是具有一定的方向性和先后顺序，尽管发展的速度有个别差异会加速或延缓，但发展是不可逆的，也是不可逾越的

不平衡性：心理发展可以因进行的速度到达的时间最终达到的高度而表现出多样化的发展模式，一方面表现出个体不同系统在发展的速度，发展的起止时间与到达成熟时期的普通进程，另一方面也表现出同一技能特性在发展的不同时期有不同的发展速率。

差异性：任何一个正常学生的心理发展总要经历一些共同的基本阶段，但在发展速度最终达到的水平以及发展的优势领域方面又千差万别。


### 中学生心理发展的特点

1. 过渡性，心理发展从前一个阶段到下一个阶段的转变，在独立性方面，中学生从完全依赖家长和教师的帮助，向独立自主的完成学习和其他活动任务，独立选择今后人生道路的一个过渡。认知活动方面，中学生从具体形象思维为主到抽象逻辑思维为主，辩证思逻辑思维为主的一个过渡。在个性方面，专业生从没有形成自己的个性，想形成稳定的个性心理过度。
2. 动荡性。中学生心理品质，个性倾向均不稳定，对于事物的认知，情感，意志水平出现起伏多变的动荡状态，心理特点突出的表现为成人感与幼稚感并存
3. 闭锁性，闭锁性是指中学生的心理活动具有某种含蓄内隐的特点，有了内心的秘密，与人交往时变得不那么坦率了
4. 社会性，社会性就是个体为了成为某个集体和社会合格的成员，通过与别人交流对必要的知识，经验，技能，行为方式，社会规范进行学习的过程，而个体所具有的这种符合社会规范要求的特征叫做社会性。
