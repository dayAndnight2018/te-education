# 8.1中学生的心理发展特征

### 个体心理发展的基本特征

**阶段性与连续性**：当某些代表性的新特征量达到一定的程度之后，就会取代旧特征而处于主导地位，表现为`阶段性的间断现象`，而`后一阶段的发展总是在前一阶段的基础上发生的`，又萌发着下一阶段的新特征，表现出心理发展的连续性

**顺序性与定向性**：心理发展总是具`有一定的方向性和先后顺序`，发展是不可逆的，也是不可逾越的

**不平衡性**：一方面表现出个体不同系统在发展的速度，发展的起止时间与到达成熟时期的不同进程，另一方面也表现出同一技能特性在发展的不同时期有不同的发展速率。

**差异性**：学生的心理发展总要经历一些共同的基本阶段，但在发展速度`最终达到的水平`以及`发展的优势领域`方面又千差万别。


### 中学生心理发展的特点

1. 过渡性。从完全依赖家长和教师的帮助，向独立自主的过渡；从具体形象思维为主到抽象逻辑思维、辩证思逻辑思维为主的过渡；从没有形成自己的个性，向形成稳定的个性心理过渡。
2. 动荡性。心理特点突出的表现为`成人感与幼稚感并存`
3. 闭锁性，具有某种`含蓄内隐`的特点，有了内心的秘密，与人交往时变得不那么坦率了
4. 社会性，个体通过与别人交流对必要的知识，经验，技能，行为方式，社会规范进行学习的过程，而个体所具有的这种符合社会规范要求的特征叫做社会性。
