# 5.5教学方法

### 教学方法

包括教师教的方法和学生学的方法


### 语言传递为主的教学方法

1. 讲授法

使用口头语言连贯地传授系统知识与技能

2. 谈话法

教师按一定的教学要求提出问题让学生解答，通过对话引导获取知识

3. 讨论法

围绕一个中心问题发表自己的看法

4. 读书指导法

通过阅读教科书或其他参考书获取知识，培养能力

基本要求：
* 教师要提出明确的目的、要求和思考题
* 教授学生读书方法
* 善于在读书中发现和解决问题
* 适当组织学生交流读书心得


### 以直观感知为主

1. 演示

实物、教具、示范性实验来教学的方法，演示法具有直观性、理论联系实际的原则

演示法使用的教具分为四类，实物、标本、模型、图片；图表、示意图、地图；实验；幻灯片、电影、录像

2. 参观法

现场教学，组织实地考察、研究，让学生获取新知识。

分为准备性参观、并行性参观、总结性参观。


### 以实际训练为主

1. 练习

运用知识反复完成一定的操作

2. 实验法

引导学生使用仪器和设备进行独立操作，培养技能和技巧。

3. 实习作业法

将知识作用于实践的教学

4. 实践活动法

让学生参加社会实践活动，培养解决实际问题的能力，学生是中心，教师是参谋。



### 引导探究为主

发现法：通过独立探究和研究活动获得知识。自行发现原理和结论。


### 情感陶冶为主

1. 欣赏教学法

对自然、人生、艺术的欣赏

2. 情境教学法

教师有目的地引入创设一定情绪色彩的场景，引起学生一定的情感体验。




### 国外教学方法改革与发展

#### 范例式教学

瓦根舍因倡导的，用好的例子进行教学。

#### 暗示教学法

洛扎诺夫倡导，广泛利用环境的暗示信息，充分利用人的可暗示性，让理智与情感统一，有意识功能和无意识功能统一，尤其是调动发掘大脑无意识领域的潜能，让学生在愉快的氛围中不知不觉接受信息。



### 教学方法的选择与运用

#### 基本依据：

1. 教学目的和任务的要求
2. 课程的性质与特点
3. 每节课的重难点
4. 学生年龄特征
5. 教学时间、设备、条件
6. 教师业务水平、实际经验、个性特点


#### 教学方法运用的灵活性、综合性、创造性：

综合性是利用多种方法组合起来；灵活性是随时对教学方法进行调整；创造性是从实际出发，在把握现有方法基础上创新创造。
