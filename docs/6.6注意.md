# 6.6注意

### 注意

注意就是心理活动或意识`对一定的对象的指向或集中`，是心理活动的动力特征之一。


### 注意的特点

1. 指向性。`有选择性`反映一定的对象，离开其他的对象
2. 集中性：心理活动`停留在被选择的对象上`的强度或紧张程度


### 注意分类

> 无意注意：`不经意`，没有目的的注意
> 
> 有意注意：`有预定目的`，主动对一定事物的关注。
> 
> 有意后注意：有预定目的，但`不需要意志力努力保持`。


### 引起无意注意的条件：⭐️⭐️
1. 刺激物的`强度`
2. 刺激物之间`显著的对比`
3. 刺激物的`活动与变化`
4. 刺激物的`新颖性`
5. 个体的`需要与兴趣`
6. 个体的`情绪与精神状态`
7. 个体的`知识经验与期待`


### 引起与维持有意注意：⭐️⭐️
1. 加深对任务的理解。
2. 合理组织活动
3. 培养稳定的间接兴趣
4. 排除内外因素干扰


### 有意后注意引起的条件：⭐️⭐️
1. 对活动浓厚的兴趣
2. 活动的自动化



### 注意的品质

1. 注意的广度：注意的`范围`
2. 注意的稳定性：保持在某一对象活动的`时间长短`
3. 注意的分配：进行两种以上的活动，注意分配道不同的对象上
4. 注意转移：主动从一个对象转移到另一个对象。


### 注意与教学⭐️⭐️

1. 根据学生外部表现，`了解学生听课状态`
2. `运用无意注意组织教学`。创造良好的社会环境，注意讲演、板书、教具的使用。`注意教学内容的组织，教学形式多样化`
3. 注意`运用有意注意的规律组织教学`
    a. 明确学习的目的和任务
    b. 培养间接兴趣
    c. 合理组织教学，防止分心
    d. 运用多种教学手段
4. 合理运用两种注意的转换组织教学。有意识培养有意后注意。


### 中学生注意力培养⭐️⭐️

1. 培养`间接兴趣`
2. 养成`良好的学习习惯`
3. 保持`良好的心理状态`
4. 重视集中注意的`自我训练`
