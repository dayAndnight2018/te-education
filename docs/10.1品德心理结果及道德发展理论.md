# 10.1品德心理结果及道德发展理论

品德的心理结构包括四种，`道德认知、道德情感、道德意志、道德行为`

**道德认知**就是对行为规范及意义的`认识`。道德认知是个体道德的一个基础，是道德情感、道德意志产生的依据，对于道德行为具有定向的意义，是行为的调节机制，品德的核心就是认知；

**道德情感**是人的道德需要是否能够得到实现而引起的一种`内心体验`。所产生的对于某种道德义务的爱憎喜恶等情感体验

1. 直觉的道德情感：就是对于具体的道德情境直接感知

2. 想象的道德情感：是对于某种道德形象的想象发生的情感体验。

3. 伦理的道德情感：是指以清晰的意识到道德概念，原则，原理为中介的情感体验

**道德意志**是个体自觉的`调节道德行为`，克服困难，实现预定的道德目标的一个心理过程

**道德行为**就是道德形成的最终环节，个体在一定的道德意识支配下表现出来的对他人社会有意义的`活动`。道德行为是衡量学生思想水平高低的一个根本标准，道德行为包括道德的行为技能和道德行为习惯，持续不断的稳定的道德行为才是一个人道德品质，而道德行为培养的关键是形成良好的道德习惯。


### 皮亚杰的道德发展阶段理论

使用对偶故事法，从他律到自律的转化发展过程，
1. **自我为中心阶段**，2~5岁，按照`自己的意愿`去执行规则
2. **权威阶段**，6~8岁，该时期儿童`服从外部规则`，接受权威指定的规范，把它看作是固定不变的，只根据行为后果来判断对错
3. **可逆性阶段**，9-10岁，`把准则看作是同伴间的共同约定，是可以改变的`。如果所有人都同意的话，规则是可以改变的，
4. **公正阶段**，11~12岁这一阶段的儿童开始倾向于`主持公正，公平`，不再刻板的按照固定规则去判断，在依据规则判断时，要考虑同伴的一些具体情况，从关心和同情的出发去判断。


### 科尔伯格的道德发展阶段理论

1. **前习俗水平**0~9岁
    a. 服从与惩罚的道德定向阶段，这一阶段儿童以来自`对外的屈从和对惩罚的逃避`
    b. 相对功利的道德定向阶段，儿童的道德价值来自于`对自己要求的满足`，偶尔也来自于对他人需要的满足

2. **习俗水平**。9~15岁
    a. 好孩子的道德定向阶段，这一阶段儿童的价值以人际关系和谐为导向，服从符合大众的意见，`谋求大家的称赞`。
    b. 维护权威和秩序的道德定向，这一阶段道德价值以`服从权威为导向`，服从社会规范，遵守公共秩序，尊重法律的权威，以法制观念判断是非，知法守法。

3. **后习俗水平**，15岁以后，
    a. 社会契约的道德定向阶段，这一阶段个体的道德价值`以法治观念为导向`，有强烈的责任感，义务感，不再把社会规则和法律看成死板的一成不变的条文，而是认识到法律和习俗的道德规范仅仅是一种社会契约。
    b. 普遍原则的道德定向阶段，这一精神个体`以价值观念为导向`，有自己的人生哲学，对是非善恶的判断有独立的价值判断，思想超越了现实的道德规范的约束行为，完全自律，而且在进行道德评价时，超越以前的社会契约所规定的责任，以公正，公平，平等，尊严这些最高的原则为标准进行思考，以普遍标准来判断人们的行为。

科尔伯格认为道德发展的顺序是固定的，但并不是所有人在同样的年龄达到同样的发展阶段，事实上很多人无法达到道德判断的最高标准，他们只能停留在较低水平的进行一个道德判断，只有大约35%的人在16~25岁以后达到后习俗水平。
