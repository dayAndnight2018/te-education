# 11.3课堂管理

课堂管理是指教师为了有效利用时间，创造愉快和富有建设性的学习环境，减少问题采取了一种组织教学设计学习环境，处理课堂行为的一系列的活动措施


### 课堂管理的功能

1. 维持——维持良好的学习环境，这是最基本的功能
2. 促进——促进学生的学习
3. 发展——帮助学生获得自我管理能力，使学生逐步走向成熟


### 课程管理的目标

1. 争取更多的时间用于学习
2. 争取更多的学生投入学习
3. 帮助学生自我管理。


### 课堂管理模式的取向

1. **行为主义取向**的课堂管理模式：`以教师为核心`来实施的这种模式，基本理念就是学生的成长发展，由`外部环境决定`他们在课堂中表现出来的不良行为或者通过学习获得，或者是因为没有学会正确的行为，在课堂管理中，教师的责任是`强化适宜的行为，根除不适宜的行为`
2. **人本主义取向**的课堂管理模式：学生有自己的决策能力，他们可以对控制自己的行为负主要责任，在课堂管理中，教师不应该要求学生百依百顺，而是`关注学生的需要情感，主动精神，向学生提供最好的机会去发掘归属感，成就感，积极的自我认同`，以此来维持一种积极的课堂环境，出现问题行为时，教师应该更多的`运用沟通技巧，引导学生分析问题的性质，后果，自己解决问题`
3. **教师效能取向**的课堂管理模式：关注`教师课堂管理技能`的提高，持这一取向的研究者认为课堂管理的好不好取决于教师的管理技能，通过培训提高教师的课堂管理技能，可以达到改善课堂管理质量的效果。

### 影响课堂管理的因素

1. 教师的领导风格
2. 班级规模
3. 班级性质
4. 对教师的期望。

### 课堂群体管理

群体是指人们为了共同的目标，以一定的方式共同活动为基础，结合结合起来的人群

学校中群体的心理功能有
1. 归属功能
2. 认同功能
3. 支持功能
4. 塑造功能

分为正式群体和非正式群体，

**正式群体**是指学校行政部门、班主任或社会团体的领导下`按照一定规章制度形成的学生群体`

**非正式群体**是学生`自由组合，自发形成`的。

教师在管理非正式群体时，
1. 要注意`摸清非正式群体的性质`
2. 对于积极的非正式群体给予`鼓励帮助`
3. 对消极的非正式权力，适当的`引导干预`。

群体动力，群体与个人行为发展变化的力量总和就是群体动力

群体凝聚力是指群体对于成员的吸引力和成员之间的相互吸引力，`凝聚力`通常称为`衡量一个班集体成功与否的重要标志`，

群体规范，群体规范是`约束群体内成员的行为准则`，包括成文的正式规范和不成文的非正式规范，

课堂气氛是指在`课堂上占优势地位的态度和情感的综合状态`。

课堂人际关系，指课堂里面人与人之间的情感和信息交流过程中形成的比较稳定的心理关系，一种是垂直的人际关系，一种是水平的人际关系，垂直的就是师生关系，水平的就是同学关系

### 课堂气氛的类型

**积极的课堂气氛**，纪律良好，师生关系融洽，学生精神饱满，注意力集中积极，思维反应敏捷，发言踊跃，教师善于点拨，积极引导课堂气氛活跃

**消极的课堂气氛**，师生关系疏远，学生无精打采，注意力分散，反应迟钝，学生处于被动的应付状态，不少学生做小动作，情绪压抑

**一般的课堂气氛**，教学中大量的课堂基本属于一般型的，它基于积极和消极之间这教学能够正常进行，教学效果一般

**对抗的课堂气氛**，课堂基本问题严重，师生关系紧张，学生随心所欲，各行其是，注意力指向无关对象，教师无法正常上课时常被学生打断，我不得不停下来维持纪律，基本上是一种失控的课堂状态。

### 影响课堂气氛的因素
1. 教师因素，教师领导方式、移情、对学生的期望、情绪状态、教学能力
2. 学生因素，课堂气氛是师生共同营造的，学生是课堂活动的主体，学生特点也是影响气氛的重要因素。
3. 课堂内务，环境因素，内部环境，又称教学的时空环境，包括教学时间安排，班级规模，设备，教具，育婴噪音，光线，空气，座位编排等。

### 创设积极的课堂气氛的方法

1. 发挥教师的主导作用
2. 尊重学生的主体作用
3. 构建和谐的师生关系，师生民主平等，树立教师威信，教师要关心爱护学生。

### 教师的领导方式

1. **强硬专断型**：`要求无条件接受一切命令`，很少表扬学生，认为没有教师监督，学生不可能自觉学习。学生典型反映屈服、不信服，厌恶，推卸责任，不愿合作。
2. **仁慈专断型**，不认为自己独断专行，表扬关心学生，口头禅：我喜欢这样做，你能让我这样做吗？`以我为班级一切的工作标准`，学生典型反映的是教师没有多大的创造性，缺乏个人的发展，班级的工作量可能是多的
3. **放任自流型**，`认为学生爱怎么样就怎么样`，很难做出决定，对学生管理没有明确目标，既不鼓励也不反对，既不参与也不提供帮助，这种典型反应道德差，学习也差，推卸责任，寻找替罪羊，容易激怒，没有合作
4. **民主管理型**，善于`和集体共同制定计划，作出决定`，在不损害集体情况下，很乐意给个别学生帮助指导，尽可能的鼓励集体活动，给予客观的表扬和批评，学生喜欢学习，喜欢和别人尤其是老师一道学习，学习的质和量都很高，相互鼓励并且独自承担某些责任，不论学生在不在课堂，要改正的问题很少。

课堂纪律管理课堂纪律具有约束性，标准性，自律性三大特征。

### 课堂纪律的类型
1. **教师促成**：在教师的指导帮助下形成的
2. **集体促成**：在集体舆论和集体压力的作用下形成的
3. **任务促成**：对于某一具体的任务对学生行为提出了具体要求
4. **自我促成**：在个体自觉努力下，由外部激励内化为个体内部的约束力。

### 课堂纪律的发展阶段

1. **反抗行为阶段**在4~5岁之前的儿童多处于这一阶段，他们的行为表现`对抗性，拒绝遵循指示要求，需要给予大量的注意`。但是畏于斥责，可能遵循他人的要求
2. **自我服务行为阶段**5~7岁的儿童都处于这一阶段，`以自我为中心`，课堂上比较容易管理，因为他们所关心的是行为后果对我意味着什么？是奖励还是惩罚？
3. **人际纪律阶段**，大多数中学生处于这一阶段，处于这一阶段的学生，其行为取向要`建立一种相互的人际关系`，他们做出的行为往往是我怎样才能取悦你联系在一起，他们这样做是因为你要求他们这样做，他们`关心自己在别人心目中的形象，希望别人喜欢自己`。
4. **自我约束阶段**，处于这一阶段的学生很少陷入麻烦，因为他们`能够明辨是非，理解遵守纪律的意义，也能够做到自我约束`，教师离开20~30分钟，回来后还依然发现依然安静的学习，这样做是因为他们知道这样做是对的，就应该这样做。

### 课堂结构与课堂纪律

`学生、学习过程、学习情境`是课堂的三大因素，三大要素相互稳定的组合模式就是课堂结构，课堂结构包括:

**课堂情景结构**包括班级管理规模的控制，班级常规的建立和学生座位的分配

**课堂教学结构**包括教学时间，合理利用课程表的编制，教学过程规划。

### 维持课堂纪律的策略

1. 建立有效的课堂规则
2. 合理组织课堂教学
3. 做好课堂监控
4. 培养学生自律品质。

### 课堂问题的行为预防

处理预防问题行为，对于困难问题要`预防为主，处理为辅`。柯宁等人总结了很好的预防问题的四个方面
1. 明察秋毫。教师要让学生知道，他们注意到了课堂里发生的每一件事情，甚至没有落下任何一件
2. 一心多用，同时跟踪监督几个活动
3. 关注整体：让尽量多的学生投入到课堂活动中
4. 转换管理，从一个活动向另一个变化。转让管理是指整个课堂和全班学生能够顺利的完成过渡，有适当灵活的进度，多样化的变化活动。

### 处理课堂问题行为

要`以最少干预为原则`，以最简短的干预纠正学生的行为，尽量做到既有效又不需打算上课

1. `非语言线索`包括目光，手势，身体靠近，触摸等
2. `表扬学生的不良反应相反的行为`，表扬是强有力的激励，要想减少不良行为，要反向去入手
3. `表扬其他做出良好行为的学生`，表扬其他学生的行为会使学生也做出这一行为
4. 言语提示：`学生犯规后，教师要马上给予提示`，延缓的提示是无效的，而且基于正面的提示以表达对于未来行为的期望，告诉学生应该遵守规则，做老师要求的事情，而不是纠缠他正在做的措施
5. 反复提示，有时候学生会拒绝听从简单的提示，有意无视学生和老师的要求，或者向教师提出请求，想以此试一试教师的意志。此时教师应`反复的给予提示`，无视任何无关请求和争吵
6. `应用后果`，当前面所有步骤都不奏效时，最后一招就是应用后果，让学生做出选择，要么听从，要么后果自负。
