# 10.3德育的概念与内容

德育的基本内容包括`思想教育，政治教育，道德教育`

思想教育是指对于各方面思想观点产生影响的教育，狭义是指形成世界观，人生观的教育

政治教育形成政治观念，信念，政治信仰

道德教育，道德意识，道德行为规范，其任务是提高道德认识，陶冶道德情感，锻炼道德意志，确立道德信念，培养道德行为习惯。

### 德育的主要内容

1. 爱国主义和国际主义教育
2. 理想和传统教育
3. 集体主义教育
4. 劳动教育
5. 纪律和法治教育
6. 辩证唯物主义世界观和人生观的教育。

### 新时期德育内容发展
1. 生存教育
2. 生活教育
3. 生命教育
4. 安全教育
5. 升学就业指导教育。
