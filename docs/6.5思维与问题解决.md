# 6.5思维与问题解决

### 思维

思维是人们对于事物的本质属性与内在联系的概括、间接的反映


### 思维有什么特点？

1. 间接性。不是单纯感觉器官感受的，而是对于感官不能直接感受的，借助某些媒介与头脑加工进行反映。
2. 概括性。抽离共同特征和本质特征；将多次感知的联系与关系加以概括。


### 思维的分类

直观动作思维：实际的动作作为支持。

具体形象思维：依靠直观的形象与表象

抽象逻辑思维：以词为中介，不再借助于动作、形象。


经验思维：来源于日常的经验

理论思维：科学的原理、定理、定律为依据，对问题分析、判断。


分析思维：遵循严密的逻辑顺序和规律，逐步推导。

直觉思维：未经推导进行合理猜测、设想。

聚合思维：求同、集中、合并，利用熟悉的规则，产生符合逻辑的结论。

发散思维：求异思维、辐射思维、解决问题时通过各种可能性进行发散，从而求得答案。


再造思维：用惯常的模式解决问题

创造性思维：用新颖的方式解决问题


### 发散思维的特征

1. 流畅性。限定时间内产生的不同想法的数量
2. 灵活性。摒弃以往的习惯与经验，开创不同的能力
3. 独创性。产生不寻常的反应，不落常规的能力。


### 如何培养创造性？

1. 培养创造性认知能力。
2. 注重创造性个性的塑造
3. 创设有利的社会环境
4. 培养创造型教师队伍


### 问题解决

问题解决就是为了从问题的初始状态达到目标状态，采取的一系列有目标指向性的认知操作过程

### 问题解决的特征

1. 目的性。为了特定的目的进行
2. 认知性。通过内在的心理加工实现
3. 序列性。包含一系列的心理活动，并且是有一定的顺序


### 问题解决的过程

1. 发现问题
2. 理解问题
3. 提出假设
4. 验证假设


### 问题解决的策略

1. 算法：将所有可能性列举出来，逐一尝试。
2. 启发法：基于一定的经验，根据问题和目标的之间的内在联系，采用较少的搜索找到解决问题的途径的策略。

手段-目的分析法：把所需要达到的问题的目标分为若干子目标，实现一系列的子目标最终解决问题

爬山法：采用一定的方法逐步缩短初始状态与目标状态的距离

逆向工作法：从目标出发，按照子目标组成的逻辑顺序逆向递归。


### 影响问题解决的因素

1. 问题情境与表征：问题呈现的知觉方式，与人们的经验越接近，越容易解决。信息在头脑中呈现方式不同，产生不同的方案
2. 定势与功能固着。思维定势有助于解决问题，但不利于创造性解决问题。功能固着是指对事物的功能产生固定的看法。
3. 原型启发：从其他事物身上找到解决问题的方法
4. 已有知识经验：经验水平影响问题解决
5. 情绪与动机：积极情绪、认真负责的态度会促进问题的快速解决。动机与问题的解决，遵循“耶克斯-多德森定律”
