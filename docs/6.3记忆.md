# 6.3记忆

### 定义

过去的经验在人脑的反映


### 记忆分类

> 瞬时记忆：只保留一瞬间的记忆，容量小，时间短，信息没有加工
> 
> 短时记忆：个体对刺激信息加工、编码；时间较短，容量有限。
> 
> 长时记忆：充分加工后的记忆，容量无限，存储时间久


> 形象记忆：以感知过得`事物形象`为内容进行的记忆
> 
> 情景记忆：对亲身经历的事物，以特定的`时间、地点`为内容的记忆
> 
> 逻辑记忆：以`抽象的知识`为内容的记忆

> 情绪记忆：以过去的某种`情感体验`作为记忆
> 
> 动作记忆：以`肢体动作`作为记忆


> 陈述性记忆：对事情`事实`的记忆；
> 
> 程序性记忆：如何做，`操作过程`。

> 外显记忆：`主动`有意识地收集经验。
> 
> 内隐记忆：已有经验对当前任务产生的影响表现出的记忆（`不由自主`）。


### 识记及其分类

无意识记：事先`没有目的`的记忆，不需要刻意集中注意力

有意识记：`有目的`、刻意识记


机械识记：多次重复，`死记硬背`

意义识记：在`理解`的基础上，根据材料内在联系进行识记



### 保持与遗忘

记忆保持：已经获取的知识在人脑中巩固的过程。

遗忘：对识记的材料不能回忆或再认，表现为`错误的回忆或再认`。

艾宾浩斯遗忘曲线：`遗忘是有规律的，先快后慢，先多后少，负加速，到一定程度后不再遗忘`。


### 遗忘的原因

痕迹衰退：遗忘是记忆`不能得到及时强化`，导致消退

干扰抑制：遗忘是因为在学习和回忆之间有`其他刺激干扰`，前摄抑制：前面对后面的影响；后摄抑制：后面对前面的影响

压抑说：由于`情绪或动机的压抑`导致的遗忘，压抑解除记忆就会恢复。

提取失败：`一时间难以提取`需要的信息。话到嘴边~

同化说：遗忘是`知识的组织和认知结构简化`的过程。积极遗忘：高级概念替代低级概念，简化观念，减轻负担。消极遗忘：被动地遗忘有意义的知识。


### 影响遗忘的因素 ⭐️⭐️

1. 学习材料的性质，包括种类、数量、难度
2. 系列位置效应。学习材料的相对位置会影响记忆的效果，首位的比中间的记忆更加深刻。首因效应、近因效应，中间较差的是渐进部分。
3. 识记材料的数量和学习程度。
4. 记忆任务的长久性与重要性
5. 识记的方法
6. 时间因素
7. 情绪和动机。


### 再认回忆

再认是对感知过的事物，`再次出现时，能够认识`的过程。

回忆是在人脑中`主动呈现`出过去经历的事物。


### 运用记忆规律，高效复习⭐️⭐️

1. 合理安排复习时间。
2. 复习方法要合理。分散复习与集中复习相结合，复习方法多样化，运用多种感官参与复习，尝试回忆与反复识记相结合
3. 复习次数要适宜，适当过度复习。
4. 重视记忆品质的培养。提高记忆的敏捷性，加强记忆的持久性，培养记忆的准确性、准备性。
5. 注意用脑卫生。重视大脑营养，适当休息。
