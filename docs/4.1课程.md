# 4.1课程

### 课程来源

最早出现在`唐宋`时期，西方出现在`《什么知识最有价值》`——斯宾塞

美国学者`博比特`在1918年出版的`《课程》`标志着课程作为专门研究领域诞生，这是教育史上`第一本课程理论专著`。

### 主要学派

#### 学科为中心

以`学科分类为基础，学科教学为核心，掌握学科基本知识、基本规律、技能为目标`。

**结构主义**：布鲁纳，强调学科的`基本结构与学生认识水平发展一致`，采用螺旋上升的方式编制课程，倡导`发现式学习`。

**要素主义**：巴格莱，课程内容是`共同要素`

**永恒主义**：赫钦斯，具有理智训练价值的`“永恒学科”`是课程的核心


#### 活动中心

`学生的活动为中心`。

主要代表是`杜威`，实用主义，强调以`实际经验为起点`，`做中学`，提出活动中心课程理论


#### 社会中心

以`适应社会需要`为中心，代表人物`布拉梅尔德`。

基本主张：重心放在社会问题、社会主要功能、关心的社会现象上

核心观点：课程不应该帮助学生适应社会，而是`建立一种新的社会秩序和社会文化`
