# 11.1班集体与班级管理

`班级`是学校行政体系中最基本的，最基层的正式组织，是`开展教学活动的基本单位`，`埃拉斯莫斯`最早提出班级一词

班集体是按照班级授课制的培养目标和教学教育组织规范起来的，以共同学习活动和直接性的人际交往为特征的社会心理共同体

### 班集体的特征

1. 明确的共同目标
2. 一定的组织结构，有力的领导集体
3. 共同生活的准则，健全的规章制度
4. 正确的集体舆论以及团结和谐向上的人际关系。


### 班集体的发展阶段

1. 初建期的`松散群体`阶段，大家对于班主任的依赖性较强，`班集体工作主要依靠教师指挥`，这一时期是班主任工作最繁忙的时期，也是班主任工作能力最经受考验的关键期
2. 形成期的`合作群体`阶段，这一阶段班集体开始稳定发展，已经班集体特征已经鲜明地表现出来，稳定下来。班集体的`凝聚力开始呈现`，大多数学生有了归属感，这一时期班主任在班级活动的组织上具有指导作用，形成期是培养班级骨干的重要时期
3. 成熟期这一阶段具有明确共同的奋斗目标，`班级已经形成了坚强的核心`，班干部，有了独立主持班务工作的能力，学生有了较强的自我教育能力，班集体形成了良好的舆论氛围和民主团结的风气。

### 班级管理

班级管理是一个动态过程，是班主任和教师根据一定的目标要求，采用一定的手段，带领全体学生对班级的各种资源进行计划组织协调控制的活动过程

### 班级管理的功能
1. 有助于`实现教学目标，提高学习效率`
2. 有助于`维护班级秩序，形成良好的班风`
3. 有助于`锻炼学生能力，学会自治自理`

### 班级管理的原则⭐️⭐️
1. 方向性原则。必须坚持正确的方向
2. 教管结合原则，要把对班级的教育工作和管理工作辩证统一起来
3. 全员激励原则，激励全班每一个学生，充分发挥他们的智力，体力，实现个体的目标和班级总目标。
4. 全面管理原则。必须面向全体，`从整体出发`
5. 自主参与原则，班级成员参与管理，发挥其主体作用。
6. 平行管理原则，`通过管理集体的间接影响个人，通过管理个人影响集体`

### 我国学校班级管理中存在的问题

1. 班主任的班级管理偏重于专断型
2. 班级管理的制度缺乏活力，学生参与度低

### 解决策略⭐️⭐️
1. 建立`以学生为本`的班级管理制度，以满足学生的发展为目的
2. 确立`学生的主体地位`
3. `训练学生自我管理班级的能力`。
