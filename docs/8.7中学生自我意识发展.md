# 8.7中学生自我意识发展

自我意识是个体`对自己以及自己周围事物关系`的意识，包括三种成分，`自我认识、自我体验、自我监控`。

### 自我意识的发展阶段

1. **生理自我**，自我意识最原始的形态，通常儿童一周岁末开始将自己的动作和动作的对象区分开来，`把自己和自己的动作区分开来`，并在与成人的交往中按照自己的姓名，身体特征，行动和活动能力来看待自己，并做出一定的评价，生理自我在3岁左右基本成熟
2. **社会自我**，儿童在3岁以后自我意识进入社会自我阶段，从轻信成人的评价过渡到自我独立评价，这时候`自我评价的独立性，原则性，批判性正在迅速发展`，儿童对道德行为的判断能力也逐渐达到前所未有水平，从`对具体行为的评价发展到具有一定概括程度的评价`，但他们的自我评价通常不涉及到个人的内心世界和人格特征，自我的调节控制能力较差，出现言行不一的现象
3. **心理自我**，心理自我在青春期开始形成发展，开始`形成自觉按照一定的行动目标和社会准则来评价自己的心理品质与能力`，他们的`自我评价越来越客观、公正、全面`。具有社会道德性，形成自我理想追求最有意义和最有价值的目标。
