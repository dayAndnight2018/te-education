# 8.5中学生人格发展

人格是构成一个人的`思想，情感，行为`的特有模式，这个独特模式包含了一个人区别于其他人的稳定统一的心理品质。人格是决定个体的外显行为，内隐行为，并使其与他人行为有稳定区别的综合的心理特征。

### 人格的特征

1. 独特性，一个人的人格是遗传，成熟，环境，教育等多种因素的交互影响而形成的
2. 稳定性，一个人的某种人格特征一旦形成就`相对稳定`下来了，但是`并不意味着不可改变`，随着生理的成熟和环境变化，人格可能会产生或多或少的变化，这是人格可塑性的一面，正因为人格具有可塑性，才能培养和发展人格
3. 整合性。人格，具有`多种成分构成的有机体，具有内在的一致性`，受自我意识的调控，当人格的结构各方面彼此和谐一致时，就会呈现出健康的人格特征，否则就会产生心理冲突，出现适应困难
4. 功能性。人格是一个人`生活成败喜怒哀乐的根源`
5. 社会性。社会化把人这样的动物变成社会的成员，`人格是社会的人所特有的`
6. 复杂性，几种人格特征表现在生活活动中的具体结合方式，因人而异，`同一人格特征在不同场合下也就不同的表现`。

### 人格组成

人格是一个复杂的结构系统，包括`气质，性格，认知风格`等。

气质是表现在`心理活动的强度，速度，灵活性，指向性`等方面的一种稳定的心理特征，`人的气质是先天的，由遗传因素决定的`，受生理影响较大，气质是人的天性，无论好坏之分，它只给人一种言行涂上某种色彩，但不能决定人的社会价值，也不能直接具有社会道德评价意义

### 气质类型

气质类型根据布拉克`希波克拉底`提出的人体中有四种性质不同的体液，血液，黄胆汁，黑胆汁和粘液，他认为正是这四种体液形成人的性质，罗马医生`盖伦`从希波克拉底的体液说出发，提出了四种气质类型
1. **胆汁质**，精力旺盛，粗枝大叶，表里如一，一感情用事
2. **多血质**，反应迅速，有朝气，活泼好动，动作敏捷，情绪不稳定
3. **粘液质**，稳重，但是灵活性不足，踏实，但有些死板，沉着冷静，但缺乏生气
4. **抑郁质**，敏锐，稳重，怯懦，孤独，行动缓慢。

### 气质的高级神经活动类型说

`巴布洛夫`在研究高等动物的条件反射时发现动物高等神经系统的兴奋和抑制有`强度，平衡性，灵活性`三种特性，根据这三种特性的结合进行了一个四种分类

1. **不可遏制型**，也就是兴奋型。具有强、不平衡的特点，对应胆汁质
2. **活泼型**，强、平衡、灵活，对应多血质
3. **安静型**，强、平衡、不灵活，对应粘液质
4. **弱型**，对应弱特点，对应抑郁质。

### 气质与教育在教育中的应用

与教学过程中，根据学生的不同气质类型，做好下方下面几方面的教育工作，

1. 正确对待学生，`克服气质偏见`
2. 针对学生气质差异，因材施教
3. 帮助学生进行气质的自我分析，自我教育，培养良好的气质品质
4. 重视`胆汁质和抑郁质`学生
5. 建学生干部队伍时应该`考虑学生的气质类型`。


### 性格

性格是人的较为稳定的态度，习惯化了的行为方式结合了一种心理特征，它是一个人的心理面貌，本质属性的独特结合，是人与人相互区别的主要方面，性格在`后天社会环境中逐渐形成`，有好坏优劣之分，最能直接反映一个人的道德风貌性格的结构，它是指个体对于自己，他人，集体，社会以及对工作，劳动，学习的态度特征

1. 性格的`意志特征`是指个人能够`自觉地确定目标，调节支配行为`，达到目的的性格特征
2. 性格的`情绪特征`是指个体稳定而且独特的情绪活动方式
3. 性格的`理智特征`是指个体在感知，记忆，想象，思维等认知过程中表现出来的认知特点和风格。

### 影响性格形成和发展的因素

1. 生理因素
2. 家庭因素
3. 学校因素
4. 社会文化因素
5. 社会实践活动
6. 自我教育。

父母教养方式及其教育影响

**专制型**：孩子的一切由父母来控制，这就会导致`消极，被动，怯懦，依赖和服从`，做事缺乏主动性，甚至会形成不诚实的性格特征

**放纵型**：溺爱，对孩子随心所欲，对孩子的教育有时候属于失控状态，这种最不成熟表现为认知`任性，幼稚，自私，野蛮无理`，独立性差，蛮横无奈，无理取闹。

**民主型**：与孩子在家里形成一种平等和谐的氛围，尊重孩子，给孩子一定的自主性，还有积极正确的指导最成熟，形成一种积极的性格，如`活泼自立，彬彬有礼，善于交往，富于合作精神，思想活跃`等。


### 良好性格的培养

1. 加强人生观，世界观，价值观的教育
2. `及时强化积极行为`
3. 充分`利用榜样的示范作用`
4. 利用集体的教育力量
5. 提供实际锻炼机会
6. 积极的进行个别指导以及提高学生的自我教育能力。

### 认知风格

认知风格是指人们在`认知过程中所偏爱的信息加工方式`，是一种比较稳定的心理特征，存在很大的个体差异，认知风格没有优劣，好坏之分，表现为学生对于信息加工的方式的某种偏爱，影响学习的学习方式

**场依存型**：对客观事物的判断，常以`外部线索为依据`

**场独立型**：对客观事物的评价，常以自己的`内部线索为依据`

---

**冲动型**：在解决认知任务时总是`急于给出答案，速度快，但是错误率高`

**沉思型**：的学生在解决认知事物时总是谨慎，全面的检查各种假设。虽然`速度慢，但是错误率很低`，

---

**继时型**：在解决问题的时候能够一步一步的分析问题，每一个步骤只考虑一种假设或一种属性，`提出的假设在时间上具有明显的先后顺序`

**同时性**，在解决问题时采取宽视野的方式，同时考虑多种架势兼顾到解决问题的各种可能性，`解决方式是发散式的`。


### 学生认知差异的教育意义

1. 创设学生认知差异的教学组织形式
2. 采取适应认知差异的教学方式
3. 运用适当适应认知差异的教学手段。


### ab型的人格类型理论

`福利曼和罗斯曼`提出了ab型的人格类型理论，A型主要是`性格急躁`，缺乏耐性，他们的成就欲高，`上进心强`，有苦干精神，工作投入，做事`认真负责`，时间紧迫感强，具有竞争意识外向，动作敏锐，说话快，生活常处于紧张状态，但办事匆忙，社会适应性差，不是属于不安定型的人格

B型性格`不温不火，举止稳当`，对工作和生活满足感强，喜欢慢不了的生活节奏，在需要审慎思考和耐心的工作中，B型人格表现比A型人格要好

### 弗洛伊德

弗洛伊德的人格三我

**本我**位于人格的最底层，是由先天的本能欲望组成的能量系统，包括各种生理需要，遵循快乐的原则

**自我**是从本我中逐渐分化出来的，位于人格结构中中间层主要是调节本我与超我之间的矛盾，遵循现实原则

**超我**超我位于人格结构的最高层次，是道德化的自我由社会规范，伦理道德，价值观念内化而来，形成的是社会化的结果，遵循道德原则。

### 人格发展的阶段理论

`弗洛伊德`人格发展理论又称为人格性欲阶段理论，这个理论中人格阶段的划分方式是根据性兴奋的不同部位所提出的

第一是**口唇阶段**，0~18个月，此时嘴唇口舌是最主要的性兴奋点，如果这个时期个体获得的刺激不够或者是过度，就会在以后的生活过程中形成口唇期人格

第二，**肛门期**18个月到3岁这个时期，肛门成为最主要的动情点，而且这一时期刚好是小孩子如厕的训练时期，如果这一时期受到创伤，就会形成肛门期人格

第三**性器期**3~6岁，此时儿童已经注意到男女性情况的不同，并且伴随着以性器官作为性兴奋点的行为，弗洛伊德特别强调这一时期此时男孩子面临着俄狄浦斯情结，又称为恋母情结，并出现了阉割焦虑，同时女孩子也面临着相似的问题

第四**潜伏期**6岁到青春期，心理表现不再那么明显

第五，**生殖期**，青春期以后，此时的儿童对于异性抱有浓厚的兴趣，如果前面几个阶段的发展正常，此时他们具有正常的性机能。

### 埃里克森的人格发展阶段理论

美国精神学家`埃里克森`认为，人格发展是一个逐渐形成的过程，必须`经历8个顺序不变的阶段`，其中前5个阶段属于儿童成长和接受教育的时期，每一个阶段都具有一个生物学成熟和社会文化环境，社会期望之间的矛盾冲突所决定的发展危机，成功而合理的解决每个阶段的危机或冲突，使个性成为积极的人格特征和健全的人格。

1. **基本的信任感对基本的不信任感**0~1.5岁，发展任务是培养信任感
2. **自主感对羞耻感**1.5~3岁，本阶段的发展任务是培养自主性。要鼓励幼儿独立探索。
3. **主动感和对内疚感**3~6岁，本阶段的发展任务是培养主动性。
4. **勤奋感对自卑感**6~12岁，本阶段发展任务是培养勤奋感。
5. **自我同一性与角色混乱**，12~18岁本阶段的发展任务是培养自我同一性，角色混乱是指个体不能够正确的适应社会环境的生活角色，这类青少年无法发现自己不能回答我是谁的问题，也不知道自己究竟是什么样的人，成为想要成为什么样的人，其他三个阶段分为亲密感对孤独感，成年早期；繁殖感对停滞感，成年中期；自我整合对绝望感，成年晚期。

### 人格特质理论

`巴尔伯特`认为人格由`共同特质和个人特质`组成，共同特质是指某种社会文化形态下的大多数人和一个群体所共有的相同的特质，个人特质是指某一个个体身上表现出来稳定独特的倾向，分为三类
1. 首要特质：是个体最典型，最有概括性的特质
2. 中心特质：是构成个体独特性的几几种重要的特质，阿尔伯特认为有5~10种中心特质即可大致的概括出一个人的整体面貌
3. 次要特质，即一一些特殊情况下表现出来不太重要的特质，较少为人所知。

### 影响人格的形成发展的因素

1. 生物遗传因素，生物遗传因素是不可缺少的影响因素。
2. 社会因素包括家庭教养方式，学校教育，同伴群体等
3. 个人主观因素，社会上各种因素影响，首先要为个人的接受和理解才能转化为个体的需要，动机和兴趣，推动个体去思考行动，此外个体已有的心理发展水平对于人格特征形成也随着年龄的增长而日益增强。
