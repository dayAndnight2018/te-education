# 5.3教学工作的基本环节

### 主要流程

备课-上课-作业布置与反馈-课外辅导-学业成绩检查与评定


### 备课的意义

`备课是上好课的前提`，备好课可以加强计划性，有利于充分发挥主导作用


### 备课的要求

1. 教师备课要`钻研教材、了解学生、考虑教法`
2. 教师备课还要完成三个计划，`学年计划、课题计划、课时计划`


### 上课的意义

`上课是教学工作的中心环节`，是教师的教与学生的学最直接的体现，是提高教学质量的关键。


### 课的类型

1. 根据任务项的数量分：单一课与综合课，一节课只完成一个教学任务，还是多项教学任务
2. 根据教学任务分：传授知识课、巩固知识课、培养技能技巧课、检查知识课
3. 根据教学方法分：讲授课、演示课、练习课、实验课、复习课


### 课的结构

新课：组织教学、检查或复习、提出新课目的、内容要点与学习要求、讲新课、小结、布置作业

技能课：组织教学，提出培养技能技巧的目的、要求，教师讲解原理、范例，在教师指导下独立练习，小结，布置作业

复习课：组织教学、提出复习目的与要求、引导学生复习、小结、布置作业

综合课：组织教学、检查与复习、提出教学目的并讲授新课、巩固新课、布置作业



### 一堂好课的评价标准

1. 目的明确
2. 内容正确，要争教学内容的科学性、思想性、系统性
3. 方法恰当。教学策略的选择和运用
4. 组织严密，有计划性
5. 语言清晰
6. 积极性高


### 作业的意义

加深学生对教材的理解与巩固，帮助学生掌握技能与技巧。及时发现学生在知识或技能方面的缺陷并加以纠正，对作业完成情况做出评价并提出进一步学习建议。


### 作业的形式

1. 阅读作业
2. 口头作业
3. 书面作业
4. 实践作业


### 作业布置的要求

1. 作业要`有目的、有重点`，符合课程标准要求
2. 考虑不同学生的能力需求
3. 分量适宜、难度适宜
4. 作业`形式多样化`
5. 要求明确，规定完成时间
6. 作业反馈清晰及时
7. 作业要有典型意义，举一反三
8. 作业应`有助于启发学生的思维`
9. `力求理论联系实际`

### 课外辅导

课外辅导是贯彻因材施教的重要措施。

1. 帮助学生解答疑问，指导学生做好作业
2. 为基础薄弱或缺课的学生补课
3. 为成绩优异的学生个别辅导
4. 对学生学习方法上的辅导
5. 对学生学习目的和态度方面的教育


### 学业成绩检查与评定的意义

1. 教师可以发现问题，进一步改进教学
2. 学校领导可以了解教学情况，加强管理
3. 学生可以获得矫正信息，调整学习
4. 家长可以了解子女的学习情况，监督孩子学习


### 学业成绩检查的方式

1. 平时考察
2. 考试
