# 7.3学习动机

学习动机是激发个体进行学习活动，维持已引起的学习活动，让行为朝一定学习目标的心理倾向或内部动力

主要包括学习需要和学习期待。


### 学习动机的功能

1. 激发学习行为
2. 指向具体目标
3. 维持和调节学习行为的强度、时间、方向


### 学习动机的分类

**内部动机**：学生的兴趣

**外部动机**：外在因素，外在动力

**直接的近景性学习动机**：活动直接引起学习动机，来源于学习内容、学习结果

**间接的远景性学习动机**：了解活动的意义与价值引起的动机，与社会意义和个人前途联系的。


**认知内驱**：`理解掌握知识、解决问题的驱动力`

**自我提高内驱**：`学业成就获得地位和威望`的需要

**附属内驱**：`为了获得长者的认可`而表现出做好工作和学习的需要



### 学习动机和学习效果的关系

1. 学习动机越强，积极性越高，学习效果越好
2. 对一项具体的学习活动，只有动机强度达到最佳水平，才能产生最佳的效果。动机不足或过分强烈均会影响学习效果。最佳动机水平随着任务不同而不同；一般，最佳动机水平为中等强度的动机；动机水平和行为效果呈现倒U型曲线。



### 学习效果对动机的影响

学习效果反作用于动机，学习效果越好，越容易激发进一步的好奇心与求知欲，提高学习的自信，增强学生进一步学习的动机。



### 学习动机理论

1. 强化理论——联结主义

某种学习行为取决于`先前的这种学习行为与刺激因强化建立起来的稳固联系`。


2. 需要层次理论——人本主义-马斯洛

生理需要、安全需要、归属与爱的需要、尊重需要、求知需要、审美需要、自我实现的需要

前四个为缺失需要，后三个是成长需要。

需要层次理论说明，缺乏动机是因`为某种缺失需要没有得到充分满足`。



### 成就动机理论——阿特金森

个体努力克服障碍，施展才能，力求又快又好地解决某一问题的愿望。

**力求成功**：目的是获得成功，选择成功概率高的活动。

**避免失败**：目的是回避可能失败的任务


#### 成就动机理论给我们带来的启示

1. 对于力求成功者，给于新颖的有一定难度的任务，安排竞争场景，评定分数激发动机
2. 对于避免失败的，安排竞争少的情景，成功要及时强化，评定时要宽松一些，避免公共场合指责错误
3. 激发学生力求成功的成分


### 成败归因理论——韦纳

成败归为：能力、努力程度、工作难度、运气、身心状况、外界环境

能力：稳定、内部、不可控

努力程度：不稳定、内部、可控

工作难度：稳定、外部、不可控

运气：不稳定、外部、不可控

身心状态：不稳定、内部、不可控

外界环境：不稳定、外部、不可控



### 习得性无助

归因一直在内部、稳定、不可控的因素上，`认为自己能力低，就会经常挫败`，形成——习得性无助



### 归因理论的启示

1. 教师可以根据学生归因方式预测学习动机
2. 利用反馈的作用可以纠正学生的归因方式，重建自信
3. 通过归因训练改变消极认知，提高学习动机


### 成就目标理论

德维克把内隐观念分为两类，内隐观念不同，成就目标就不同：
1. 能力增长观：能力是可以提高的
2. 能力实体观：能力是固定的。

埃利奥特等将成绩目标划分为成绩趋近目标和成绩回避目标，平特里奇将掌握目标分为掌握趋近和掌握回避。

掌握趋近：关注知识的掌握和能力的提高。

掌握回避：避免不能完成任务的情况，在任务中不出错

成绩趋近：力求取得好成绩、好名次

成绩回避：避免在考试中取得差分数、差名次



### 自我效能感理论——班杜拉

人对自己`能否成功从事某一成就行为的主观判断`。人的行为受结果因素（强化）和先行因素（强化期待）的影响。

期待分为结果期待和效能期待。前者是对结果的预测，后者是对自己能否成功胜任某项活动的预测。


#### 自我效能感的作用

1. 决定人们对于活动的选择
2. 影响在困难面前的态度
3. 不仅影响新的行为习惯，也影响已经习得的行为表现
4. 自我效能还会影响活动时的情绪


#### 影响自我效能感的因素

1. 自身的成败经验
2. 替代经验（观察到与自己一样或不如自己的人成功，效能感提高）
3. 言语暗示，他人的言语暗示可以提高自己的效能感
4. 情绪唤醒。高水平的情绪唤醒使成绩降低影响自我效能感。



### 影响学习动机的因素

1. 学生的需要与目标结构
2. 年龄特点
3. 性格与个性差异
4. 理想与价值观
5. 焦虑程度：中等焦虑是最佳的状态。
6. 家庭与社会环境的影响
7. 学校教育起到主导作用


### 激发学习动机

1. 创设问题情景，激发兴趣，维持好奇心
2. 设置合适的目标
3. 根据作业难度，恰当控制动机水平
4. 表达明确的期望
5. 提供明确、及时、经常的反馈
6. 合理运用外部奖赏
7. 有效运用表扬
8. 对学生进行竞争教育，适当开展学习竞争
