# z1.1教育观

教育观就是人们对教育所持有的看法，教育观的核心是教育目的。

素质教育是依据人的发展，社会发展实际需要，以`全面提高全体学生的基本素质`为根本目的，以`尊重学生主体性，主动精神，注重开发人的智慧潜能，注重形成人的健全个性`为根本特征的教育。简单来说就是面向全体，全面发展，个性健全。

### 素质教育的内涵

1. 素质教育以提高国民素质为目的
2. 素质教育是面向全体学生的教育
3. 素质教育是促进学生全面，生动活泼的可持续发展的教育教育就全面性，主体性，可持续性
4. 素质教育是促进学生个性发展的教育
5. 素质教育要着力提高学生的社会责任感，创新精神，社会实践能力。

### 素质教育的外延

素质教育不是对特定阶段，特定学校提出的要求，而是对各级各类学校提出的要求是连续的`全方位，全过程`的教育活动，

1. 素质教育应该贯穿于幼儿，中小学，职业成人教育，高等教育等各级各类学教育，还应贯穿于学校教育，家庭教育，社会教育等各个方面。
2. 实施素质教育必须把德育，智育，体育，美育，劳育有机统一在学校教育范围内，从纵向上来看存在于教育活动的各个环节，从横向来看素质教育渗透在德智体美劳各个方面。

素质教育的根本目标，总目标是`全面提高国民素质`具体目标
1. 促进学生身体发育
2. 促进学生心理成熟
3. 造就平等的公民
4. 培养个体的生存能力，基本品质
5. 培养学生自我学习习惯，爱好和能力
6. 培养学生的法律意识
7. 培养学生的科学精神和态度。

### 素质教育的基本任务
1. 培养学生的身体素质
2. 培养学生的心理素质
3. 培养学生的社会素质。

### 素质教育所倡导的观念

1. 在学习方式方面，强调学生的`自主，合作和探究`
    a. 自主学习关注的是主体性和能动性
    b. 探究学习以问题为依托进行学习，主动探究解决问题的过程
    c. 合作学习是指学生以小组为单位进行学习的方式
2. 素质教育的教学观。⭐️⭐️
    a. 教学从`以教育者为中心转向以学习者为中心`
    b. 教学`从教会学生知识转向教会学生学习`
    c. 教学`从重结论轻过程，转向重结论的同时更重过程`
    d. 教学`从关注学科转向关注人`。

### 评价观念

1. 重视`发展`，淡化甄别，选拔，实现评价功能的转化
2. 重视`综合评价`，关注个体差异，实现评价指标的多样化
3. 强调`质性评价定性与定量评价相结合`，实现评价方式多元化
4. 强调`参与和互动，自评和他评相结合`，实现评价主体的多元化
5. 注重`过程终结性评价与形成性评价相结合`，实现评价重心转移。

### 素质教育的基本要求⭐️⭐️
1. 面向全体学生
2. 促进学生全面发展
3. 促进学生创新精神，实践能力培养
4. 促进学生生动，活泼，主动的发展
5. 着眼于学生的终身可持续发展。

### 实施素质教育的途径和方法⭐️⭐️

基本途径包括`课堂内外和学校内容`两大方面。
1. 改革学科教学
2. 重视社会实践
3. 谋求学校，家庭，社区教育的结合。

### 实施素质教育的常用方法
1. 创建全新的课堂教学方法
2. 提高思想品质，心理素质等

### 创新全新的课堂教学方法⭐️⭐️

要更彻底的更新，转变教学观念是最基础的一环
1. 从注重学生外在变化转向内在变化
2. 从强调学习结果转向学习过程
3. 从单纯教师教的方法转向师生共同活动
4. 从封闭的教学形式转向开放的教育形式。

### 提高思想品质，心理素质等常用方法
1. 自我教育法
2. 心理疏导法
3. 行为强化训练法
4. 陶冶感染法。

### 实施素质教育的误区

1. 素质教育就是不要尖子生
2. 素质教育就是要学生什么都学，什么都好
3. 素质教育就是不要学生刻苦学习，减负，就是不给或少给学生留课后作业，这是误解的学生真正的愉快来自于刻苦的努力，而获取成功之后的快乐学生真正的负担不是是不情愿的学习任务。
4. 素质教育就是要使教师成为学生的合作者，帮助者，服务者。教师首先是知识的传播者，智慧的启迪者，个性的塑造者，人生的引路人，潜能的开发者，其次才是学生的合作者，帮助者，服务者
5. 素质教育就是多开展课外活动，多上文体课，素质教育主渠道是教学主阵地，也是课堂。
6. 素质教育就是不要考试，特别是不要百分制考试，这也是对考试的误解，考试作为评价手段是衡量学生发展的尺度之一，也是激励学生发展的手段之一
7. 素质教育会影响升学率，这也是误解的，素质教育的目的是促进学生的全面发展，升学率只是衡量教学质量的标准之一，真正的素质教育不会影响升学率，因为素质教育强调科学刻苦，有针对性的学习有助于升学率的提高。
