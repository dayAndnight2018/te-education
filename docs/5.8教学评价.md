# 5.8教学评价

### 概念

对教学活动及教学结果进行测量、分析、评定


### 教学评价内容

1. 对`学生学习结果`的评价
2. 对教师`教学工作`的评价
3. 对`课堂教学的各个要素`进行评价


### 教学评价的基本类型

#### 诊断性评价：`学期开始或单元开始`，进行摸底考试。

可以查阅被评价者此前的成绩记录、摸底测验、必要的学习要素调查表。

主要功能：
1. 检查学习准备情况
2. 决定对学生适当安置
3. 辨别造成学生学习困难的原因



#### 形成性评价：`在教学过程中`为了改善教学活动进行的过程性评价。

包括对学生的口头提问、书面测验等

功能：
1. 改进学生的学习
2. 为学生的学习定步
3. 强化学生的学习
4. 给教师提供反馈


#### 总结性评价：`在一个学期或一门课结束的时候`，对学生的学习结果评价。

功能：
1. 评定学生的学习成绩
2. 证明学生掌握知识技能的程度，以及达到教学目标的程度
3. 确定学生在后续教学活动中的学习起点
4. 预言学生在后续教学活动中成功的可能性
5. 为制定新的教学目标提供依据


#### 决对性评价：目标参照性评价，`编制试题测量学生掌握情况，是否达到了教学目标的要求`。

可以`衡量学生的实际水平`，了解学生对知识与技能的掌握情况，适用于`升级考试、毕业考试、合格考试`

不适用于甄选人才


#### 相对性评价：常模参照性评价，`依据学生成绩在班内的位置，评价成绩的优劣`，不考虑是否达到教学目标。

甄选性强，作为`选拔人才、分类排队`的依据。但是不能明确学生的真正水平，不能表明在学业上是否达到了特定的标准，对个人努力情况也不够重视。


#### 个体内差异评价：对同一个体的过去与现在进行比较，或同一个体的不同方面比较

充分尊重个体差异，减轻了评价对象的压力

评价本身缺乏客观标准，不容易给评价对象一个明确的目标，难以发挥作用。



#### 内部评价：自我评价

如果态度端正，则会有较高的准确性，为外部评价提供丰富的信息；还能增强被评价者自我评价意识和能力；有利于自我反馈调节

自我评价无法横向比较，主观性强，无法客观评价



#### 外部评价：被评价人之外的专业人员对其评价。

外部评价更加真实客观，更容易看到成绩与问题；

外部评价要求比较严格，组织工作较难，花费人力财力较多
