# 11.5教师心理

### 教师角色的心理结构

1. 角色认知，角色认知就是角色扮演者对角色的社会地位，作用及行为规范的认识和对与社会的其他角色关系的认识，角色认知是角色扮演的先决条件，一个人能否成功的扮演各种角色，取决于他对这一角色的认知程度
2. 角色体验，角色体验是个体在扮演一定角色过程中，由于受到各方面的评价与期待，产生了一种情绪体验
3. 角色期待，角色期待是指角色扮演者对自己和对别人应该表现出什么样的行为，或者应该成为什么样的角色想法和期望。

### 教师的职业角色

1. 传道者角色具有传递传统道德价值观念的使命
2. 授业解惑者要将自己获得的知识，经验，技能进行精细加工整理，传授给年轻一代
3. 示范者，教师言行是学生学习和模仿的榜样
4. 教育教学活动的设计者，组织者，管理者
5. 家长代理人，父母，朋友，知己
6. 研究者角色和学习者，学者角色，教师应该积极的参与教学研究，教学实验改革，不断提高自身的教育理论水平和教育质量。

从新手型教师逐渐成长为一个胜任教学工作的熟手型教师，主要经历三个阶段
1. 教师角色的认知
2. 教师角色的认同
3. 教师角色的信念。

### 教师的心理特征

一般包括教师的知识结构和教师的教学能力

教学认知能力，教学认知能力是指教师对于所教学科的定理，法则，概念等概括化程度，以及对于所教学生的心理特点，自己所使用的教学策略的理解程度，教学操作能力是指教师在教学中使用策略的水平，其水平高低主要看他们是如何引导学生掌握知识，积极思考，运用多种策略解决问题的，它是课堂教学教育能力的集中体现

教学操作能力主要包括以下方面的教学策略
1. 制定教学目标的策略
2. 编制教育计划策略
3. 教学方法选择与运用
4. 教学材料，教学技术的选择设计
5. 课堂管理策略
6. 对学习和教学进行测试评价的策略。

教学监控能力是指教师为了保证教学达到预期的目的，而在教学的全过程中将教学活动本身作为意识对象，不断对其积极主动的计划检查，评价，反馈，控制调节的能力。

### 教师的人格特征

主要包括职业信念和职业性格。有关职业信念的心理学研究主要集中在教学效能感和教学归因两方面，教学效能感一般是指教师对自己影响学生行为和学习结果的能力的一种主观判断，这种判断会影响教师对学生的期待和指导，从而影响教师的工作效率，教学效能感又分为两部分，一般教学效能感和个人教学效能感，前者教师对于教育学的关系教育在学生身心发展中的作用等问题，一般看法，后者是指自己能够有效的影响学生，相信自己具有教好学生的能力。

### 教师的行为特征

主要包括教师的教学行为和期望行为，教师的期望行为也叫做`罗森塔尔效应`和皮格马利翁效应即教师的期望或明或暗的传递给学生会，使学生按照教师所期望的方向塑造自己的行为，

### 教师期望的作用
1. 激励作用，教师以激励的教育方式诱导学生产生内驱力，从而把教师的教学教育要求内化为学生的自觉行动，便会使学生获得生动，活泼，主动的发展
2. 调整作用，当教师的期望与学生的思想认识达到同一频率的时候，师生之间产生情感，思维各方面的共振共鸣。
3. 转化作用，每个学生都有一种内隐的潜质及积极向上的要求，自我完善的愿望，自控和调节的适应能力，这种潜质一旦被激发，就会展现其积极的方面
4. 资源性作用，学生正处于心理发展过渡期，教师应该给予心理支援，尊重他们的人格，注重发展，发现其闪光点，有针对性的给予各种帮助，满足他们的心理需要。

### 教师成长的阶段
1. 关注生存阶段。一般是新教师，他们非常关注自己的生存适应性，最担心的问题是学生喜欢我吗？同事们如何看我领导是否觉得我干的不错？因而他们可能会把大量的时间都花在如何与学生搞好个人关系，想方设法控制学生，而不是更多的考虑如何让学生获得学业学业上的进步。
2. 关注情景阶段。他们关心的是如何教好每一堂课的内容以及班级大小，时间压力，备课材料是否充分等教学情景相关的问题，传统教学评价集中关注这一阶段，一般来说，老教师比新教师更关注此阶段
3. 关注学生阶段，当教师顺利的适应了前两个阶段之后，成长的下一个目标便是关注学生，这一结论的教师呢将会考虑学生的个别差异，认识到不同发展水平的学生有不同的需要，根据学生的差异来采取适当的教学，促进学生发展，能否自觉关注学生是衡量一个教师是否成熟的重要标志之一。

教师成长的发展途径主要两方面，一方面通过`师范教育`培养新教师作为教师队伍补充，第二，通过`实践锻炼`提高在职教师的素质。

促进教师成长有以下几种方法，第一，观摩分析优秀教师的教学活动，第二，开展微格教学，第三，进行专门训练，第四，进行教学反思。

布鲁巴奇等人认为教学反思的方法主要有
1. 反思日记
2. 详细描述
3. 交流讨论
4. 行动研究。

美国教育心理学家波斯纳提出了教师成长公式，即经验+反思=成长。

### 教师心理健康标准
1. 积极的悦纳自我，真正了解正确评价，乐于接受并喜欢自己
2. 有良好的教育认知水平，能够面对现实，积极的去适应环境，教育工作要求
3. 热爱教师职业，积极的爱学生
4. 具有稳定且积极的教育心境
5. 能够控制各种情绪，情感
6. 和谐的教育人际关系
7. 能适应改造教育环境
7. 具有教育独创性。

### 影响教师心理健康的主要因素

1. 主观方面，教师的心理健康受其人格特征，心理素质等自身因素的制约
2. 客观方面，家庭，学校，社会环境的影响不容忽视
3. 工资待遇，社会地位，劳动强度不成正比，挫伤积极性，是教师缺乏成就感
4. 学校组织中人际关系复杂
5. 家庭关系不和谐。

### 教师职业倦怠

职业倦怠是个体在长期的职业压力下缺乏应对资源，应对能力产生的身心浩劫的状态，马勒斯等人认为职业倦怠主要发现表现为三个方面
1. 情绪耗竭：个体情绪情感处于极度的疲惫状态，工作热情完全丧失
2. 去人性化，即刻意在自身和工作对象间保持距离，对工作对象和环境采取冷漠忽视的态度
3. 个人成就感低，表现为消极的评价自己，贬低工作的意义和价值。

### 教师心理健康维护

1. 提高心理调适能力
2. 优化学校环境
3. 构建社会支持网络

提高心理调试能力
1. 培养正确的压力观
2. 改善自我观念
3. 正确应对挫折与压力
4. 建立积极的思维方式内在对话
5. 采取合理有效的工作方式学会休闲

优化学校环境
1. 实行人性化管理，增强教师的职业满意感
2. 重视教育教师心理健康教育，增强教师的自我调适感
3. 开展丰富多彩的活动，增强教师的人际和谐感
4. 健全教师心理健康的校内保障体系

构建社会支持网络
1. 社会各界要对教师角色期待进行合理定位
2. 国家应该切实采取措施提高经济待遇和社会地位
3. 教育部门应该探索有效的教师教育培训体系，将职前职后培训有机结合，为教师提供职业发展机会。
