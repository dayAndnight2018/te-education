# 5.1教学的概念意义和任务

教学是在一定教育目的规范下，教师的教和学生的学共同作用的传递经验的过程

### 概念辨析

教育与教学：教育包含教学，教学是学校教育的基本途径，还有课外活动、生产劳动、社会活动等渠道

教学与智育：智育属于教育的一个部分，智育的常用手段是教学。

教学与自学：是否有教师指导。


### 教学的意义

1. 系统传播知识，促进学生发展，是社会经验再生产、适应并促进社会发展的有力手段
2. 是全面发展教育，实现培养目标的重要环节
3. 教学是学校教育的中心工作，必须坚持以教学为主


### 教学的一般任务

1. 引导学生掌握科学文化知识和技能（基础）
2. 发展智力（核心）
3. 发展体力（保证）
4. 培养审美情趣和审美能力
5. 培养道德品质（方向）、个性心理（理想目标），形成科学的世界观
