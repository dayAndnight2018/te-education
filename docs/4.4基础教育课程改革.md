# 4.4基础教育课程改革

2001年6月进行第八次基础教育课程改革：`为了中华民族的复兴，为了每位学生的发展`


### 具体目标

1. 课程功能转变。`从注重知识传授到注重主动学习态度的培养、价值观的形成`
2. 课程结构体现均衡性、综合性、选择性
3. 密切联系生活
4. 改善学生学习方式
5. 建立与素质教育理念一致的评价与考试制度
6. `实施三级课程管理制度（国家、地方、学校）`


### 校本课程开发的特点

1. 主动有计划的变革策略
2. 民主开放的课程决策过程
3. 尊重学校师生的独特性和差异性
4. 是教育制度内的权利与资源重新配置的过程
5. 是课程理论与实践不断丰富完善的过程
6. 校本课程开发是国家课程开发的重要补充


### 基础教育改革的内容

一、 重建课程结构
1. 实施`九年一贯制`义务教育
2. 高中以`分科`课程为主
3. 从小学到高中设置`综合实践活动`作为必修
4. 农村中学课程要为当地社会经济发展服务

二、制定国家课程标准

它是`教材编写、教学、评估、考试命题的依据`，也是国家管理和评价课程的基础。

三、改善课程实施过程

1. 教师是组织者和引导者
2. 学生是主体
3. `教材是教学内容的重要载体`
4. 加强师生沟通交流

四、规范教材的开发管理

1. 完善管理制度
2. 强化教材质量
3. 严格审定

五、建立发展评价体系

对学生的发展进行评价，对教师的发展有所促进，对课程本身改善的价值

六、实行三级课程管理制度

`国家、地方、学校`


### 综合实践活动的特点

1. 实践性。以实践活动为基础开发、设计与利用课程资源的
2. 综合性。着眼于学生全面发展
3. 开放性。密切保持学生生活的联系
4. 生成性。强调学生学习发展过程中的经验生成
5. 自主性。充分尊重兴趣爱好
