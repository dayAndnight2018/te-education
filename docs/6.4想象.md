# 6.4想象

想象是人脑对已经存储的表象进行加工，形成新的形象的过程。


### 想象的功能

1. 预见功能：预见活动的结果
2. 补充功能：弥补时空限制
3. 替代功能：某种需要不能得到满足时，通过想象从心理上得到补偿。
4. 调节功能：对机体的生理活动有调节作用。


### 想象的种类

无意想象：`没有特定的目的`，不由自主的产生。

有意想象：`有预定的目的`，自觉进行的想象。

再造想象：根据词语、符号，在头脑中形成与之相对应的新形象的过程。

创造想象：按照一定的目的、任务，使用自己以往积累的表象，在头脑中`独立地创造`出新形象的过程。

幻想：与生活愿望相结合，指向于未来的想象。分为`科学幻想、理想、空想`三种形式。
