# 8.2中学生的认知发展

### 心理发展的实质

皮亚杰认为所有的生物都有`适应和建构`的倾向。`动作`是感知的源泉和思维的基础，儿童心理发展的实质和原因就是`主体通过动作完成对客体的适应`，适应的本质在于获取机体与环境的平衡，适应分为两种不同的类型：

> **同化**：面对新的刺激环境时，`把刺激整合到已有认知结构中`
> 
> **顺应**：机体不能利用原有的图式接受和解释新刺激时，`认知结构发生改变`来适应新刺激的影响。

平衡是指同化和顺应之间的均衡，儿童通过同化和顺应达到机体与环境的平衡，如果失去平衡，则需要改变行为来重建平衡。


### 皮亚杰的认知发展阶段理论

**感知运动阶段**，也就是0-2岁，感觉和动作进行分化，`客体永久性`的概念形成，问题解决能力开始得到发展，`延迟模仿产生`

**前运算阶段**2~7岁，这一阶段主要表现为早期的信号功能。
1. 自我中心性，所谓自我中心性是指儿童往往`只注意主观的观点`，不能从客观的事物出发，只能考虑自己的观点，无法接受别人的观点，也不能将自己的观点与别人的观点协调； 
2. 思维具有不可逆的性，往往是根据知觉到的表面现象做出反应，不能推断事实
3. 泛灵，认为任何物体都是有生命的
4. 不合逻辑的推理，不能理顺整体和部分的关系；
5. 认识活动具有具体性，还不能进行抽象的思维运算

**具体运算阶段**
1. 具有去自我终身性，它能够独立于直接经验之外的事物，能够考虑多个感知特征，去中心化，得出具体问题的解决方法
2. 可逆性
3. 守恒。此阶段儿童已经掌握了数量，面积，重量，体积等守恒，在某些变化中抓住事物本质特征而不像之前的阶段只注意到表面特征和突出特征，此阶段的儿童能够进行分类
4. 序列化，序列化是指能够根据大小，体积，重量等其他特征对一系列要素进行心理上的一个排序。

**形式运算阶段**，11岁到成人
1. 命题之间的关系
2. 假设演绎的一个推理
3. 类比推理
4. 抽象逻辑思维可逆与补偿
5. 反思能力
6. 思维的灵活性
7. 形式运算思维的逐渐发展。


### 维果斯基的发展理论——文化历史发展理论

维果斯基强调`社会文化`在人类认知发展中的作用，创立了文化历史发展理论，维果斯基区分了两种心理技能

作为动物进化结果的低级心理机能，

作为历史发展结果的高级心理技能。提出心理发展实质是在环境和教育影响下个体的低级心理机能基础上逐渐向高级心理机能转化的过程，内化说是维果斯基心理发展的核心思想。

教学与发展的关系，第一，最近发展区的概念一是儿童的现有水平及有一定的已经完成的发展系统所形成的儿童心理技能的发展水平，也就是儿童独立解决问题所具备的心理发展状态，第二，可能达到的发展水平也就是通过教学所获得的潜能，教育中教师要提供给学生力所能及而又高于学生当前发展水平的任务是他们跳一跳摘桃子。

教学应该走在发展的前面，包含两层含义，第一，教学的发展中起出的作用，第二，教学创造着最近发展区。适时辅导学生是教学的必由之路，就是之下的你，如果司机认为教师可采用教学支架进行支架式教学，记得学生试图超出那些知识水平的问题是基于支持和指导，帮助其顺利的通过增强方式去使之能够独立完成任务。

### 中学生认知发展的特点

中学生的视觉，听觉，运动觉发展很快，第二，知觉的发展，知觉的有意义和目的性进一步提高。

中学生注意发展的特点，第一，有意注意发展明显，最终替代无意主义的主导地位，第二，不论何种注意都在逐步深化，第三，注意特征存在个体差异。中学生记忆发展的特点，第一，中学生记忆发展总体趋势随着年龄增长，记忆力不断提高到16岁趋于成熟，第二，同一年龄的中学生所受实际材料的影响，记忆效果不一样，第三，中学生短时记忆的广度和随着年龄的增长不断增大。第四，随着年龄的增长，中学生无意进入危机，效果都不断提高，但有意记忆逐渐占主导地位，第五这一生以理解记忆为主的。这个记忆手段第六，抽象记忆在中学阶段中占据主要地位。

### 中学生思维发展特点
1. 抽象逻辑思维占主导，
2. 形式逻辑思维逐渐发展
3. 辩证逻辑思维迅速发展。
