# 6.2知觉

### 定义

知觉是在感觉的基础上，人脑对客观事物的`整体属性`的反映


### 知觉分类

物体知觉与社会知觉。

社会知觉是`对自己、对别人、对群体`的知觉。


### 常见的知觉偏差

1. 刻板印象：认为`某个群体`的人全部`都有某种特点`
2. 晕轮效应：我们认为某人具有某种特征时，对`其他的方面`就有类似的判断
3. 首因效应：总体印象形成上，`最初获取的信息`比后来的信息影响大
4. 近因效应：总体印象形成上，`新获取的信息`比原来的信息影响大
5. 投射效应：某个体有某特征，就`认为他人也有类似的特征`


### 知觉的特征 ⭐️⭐️

1. 选择性。有意识关注指定的对象
2. 理解性：以知识经验为基础对事物进行加工处理。
3. 整体性：把直接作用于感官的多重属性统一整体的过程。
4. 恒常性：客观事物本身不变，知觉条件会在一定范围内变化时，知觉映像不变。


### 知觉的整体性取决于 ⭐️⭐️

1. `知觉对象的特点`
2. 知觉对象`各部分之间的强度关系`
3. 知觉对象`各部分之间的结构关系`
4. 知觉者的`主观状态`
