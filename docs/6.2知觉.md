# 6.2知觉

### 定义

知觉是在感觉的基础上，人脑对客观事物的整体属性的反映


### 知觉分类

物体知觉与社会知觉。

社会知觉是对自己、对别人、对群体的知觉。


### 常见的知觉偏差

1. 刻板印象：对某个群体特征进行概况，认为那个群体的人就是这样的特点。
2. 晕轮效应：我们认为某人具有某种特征时，对其他的方面就有类似的判断
3. 首因效应：总体印象形成上，最初获取的信息比后来的信息影响大
4. 近因效应：总体印象形成上，新获取的信息比原来的信息影响大
5. 投射效应：某个体有某特征，就认为他人也有类似的特征


### 知觉的特征

1. 知觉具有选择性。可以自觉地区分背景和对象。
2. 知觉的理解性：人以知识经验为基础对感知的事物进行加工处理。
3. 整体性：根据经验把直接作用于感官的多重属性统一整体的过程。
4. 恒常性：客观事物本身不变，知觉条件会在一定范围内变化时，知觉映像不变。


### 知觉的整体性取决于

1. 知觉对象的特点
2. 知觉对象各部分之间的强度关系
3. 知觉对象各部分之间的结构关系
4. 知觉的整体性依赖于知觉者本身的主观状态
