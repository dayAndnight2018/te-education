# z1.2学生观

学生观就是教师对于学生的基本看法，它影响教师对学生的一个认知和态度行为，进而影响学生的发展。

### 人的全面发展思想

确立正确的学生观的基础是马克思主义人的全面发展思想，
1. 学生是具有`主体性`的人
2. 学生是有着`身心发展各个方面需要完整的人`
3. 学生是`有发展潜力的人`
4. 学生是一个整体，`全面发展是全体学生的发展`
5. 学生是`有差异，有个性的人`。

### 以人为本的学生观

坚持以人为本，必须以学生作为教育活动的出发点。以人为本的学生观的核心`是一切为了每一位学生的发展`。

学生的身心发展是有规律的，个体身心发展一般规律有顺序性，阶段性，不平衡性，互补性，个别差异性和整体性

1. 顺序性是指个体身心发展是由低级到高级，简单到复杂，量变到质变的连续不断的发展过程
2. 阶段性是指个体在不同年龄阶段表现出身心发展不同的总体特征和主要矛盾
3. 不平衡性是指同一方面的发展速度在不同年龄阶段是不平衡的，不同方面在不同时期是不平衡的
4. 互补性是指机体某一方面机能受损，可通过其他方面超常发挥，得到部分补偿
5. 个别差异性不同个体同一方面的发展速度和水平不同，不同个体不同方面的发展存在差异，不同个体所具有的个性心理倾向不同，个别差异性也表现在性别之间
6. 整体性。学生以整个身心投入教学生活，并以整个身心来感知，体验，享受和创造这种教学生活。

学生是具有巨大的发展潜能的，教师应该坚信每一个学生都可以积极成长，是有培养前途的，是追求进步和完善的，是可以获得成功的，因而对于教育好，每一个学生都应该充满信心。

作为发展中的人，也就意味着学生还是一个不成熟的人，是一个正在成长的人。

学生并不是单纯抽象的学习者，而是具有丰富个性的完整的人。每个学生都有其自身的独特性，要正视学生的个别差异，克服按照统一标准和尺度去衡量学生追求完全趋同，整齐划一的弊病，要根据学生各个方面的情况进行因材施教。学生和成人之间有很大的差别，学生的观察，思考，选择体验都会成人成人有明显的不同。

学生是具有独立意义的人，每个学生都是独立于教师头脑之外，不以教师的意志为转移的客观存在，学生是学习的主体，素质教育强调学生在学习学习活动中是`认识的主体，实践的主体，发展的主体`是学习的主人，教育的根本目的在于`促进学生主体性的发展`，学生是责权的主体，学生是认识世界，改造世界的独立主体，在教育教学活动中具有学习的主自主需求和动力，拥有享受相关需求的权利，教师要尊重学生的主体性需求，同时要引导学生学会承担责任，认识到权利和责任是并存的，更是统一的在享有一定权利，同时也必须承担着一定责任。

中学生全面发展教育的实施，全面发展教育由德智体美劳构成，他们相互依存，相互促进，相互制约，构成一个有机整体
1. 德，在全面发展中起着灵魂和统帅作用
2. 智，起着前提和支持作用
3. 体是物质基础
4. 美起到动力作用
5. 劳可以综合德智体美的作用。

### 教育公正

主要包括保证原则，机会平等原则和补偿原则
1. 保证原则，保证每个人受教育的权利实现。
2. 机会平等原则，要求社会平等的尊重每一个学生，让所有的受教育者在平等条件下选择并吸收适合提高自身素质的养分。
3. 补偿原则。补偿原则要做的就是甄别出处于社会不利地位的阶层，根据他们的自身特殊地位，不同观念对于教育的要求来看待问题，解决问题，以最大限度满足这一阶层的利益为标准来确定教育资源的分配和利用，实现教育相对稳定的正常运转。
