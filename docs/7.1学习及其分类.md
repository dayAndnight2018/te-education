# 7.1学习及其分类

### 学习的内涵

学习是个体在特定情境下由于`练习或反复经验`而产生的`行为或行为潜能`的相对持久的变化。

1. 学习是一种适应活动
2. 学习是人和动物共有的普遍现象
3. 学习是`反复经验`引起的
4. 学习是有机体`后天习得经验`的过程
5. 学习可以是有意的，也可以是无意的
6. 学习引起的是`相对持久的行为或行为潜能的变化`


### 学习主体的分类

动物学习、人类学习、机器学习

动物学习依赖于`消极`适应环境，人类是`积极主动`适应并改造自然环境的；

动物主要依赖于`直接经验`，人类可以`从社会实践中习得经验`；

动物学习局限于`第一信号系统`，人类学习主要是`第一、第二信号系统的协同`。（第一信号系统依赖具体事物刺激，第二信号系统依赖语词）

### 加涅学习水平的分类

1. 信号学习：对`某种信号`做出反应，过程为刺激-强化-反应
2. 刺激-反应学习：对`某种情景中的刺激`做出反应
3. 连锁学习：`两个以上的刺激`-反应动作
4. 言语联结学习：`言语连锁`化
5. 辨别学习：识别`多种刺激的异同`，并对之做出不同反应
6. 概念学习：对`刺激进行分类`，对一类刺激做出同样的反应
7. 规则或原理学习：学习`两个概念之间的关系`
8. 解决问题的学习：`使用规则或原理解决问题`

### 加涅学习结果分类

1. `认知`领域：智慧技能、认知策略、言语信息

2. `动作`技能

3. `情感`领域：态度


### 奥苏泊尔学习分类

1. `接受学习与发现学习`（学习方式）
2. 有意义学习与机械学习（学习内容与学生认知结构关系方面）


### 阿瑟雷伯学习分类

内隐学习：`不知不觉`就获得了经验

外显学习：`有意识`的解决问题，具有明确的表象
