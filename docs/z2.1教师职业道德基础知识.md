# z2.1教师职业道德基础知识

教师职业道德是教师在从事教育劳动时应该遵循的行为规范和品德的总和，`师德师风`是评价教师队伍素质的第一标准。

### 教师职业道德的形成

1. 教育劳动实践是客观基础。
2. 受到生产关系和阶级利益的制约
3. 批判继承了历史上优秀教师职业道德。

### 教师职业道德的原则

1. 基准性，是教师在道德实践中`必须遵循的基本准则`。
2. 本质性，`教师职业道德原则`是教师职业道德的社会本质最直接，最集中的反应，是教师职业道德区别于其他各种不同类型道德的最根本，最显著的特征
3. 稳定性，往往是概括性的，稳定的
4. 自身独特性，是教师个人，他人以及与社会间关系的根本行为准则，与其他职业道德不同。

### 教师职业道德的修养

教师把教育教学活动中必须遵循的客观的`外在的道德要求转化为个人主观的内在的道德观念`，`成为自己的思想行为准则`的自我教育，自我锻炼，自我改造的活动。基本特点有：
1. 自我性：师德修养的主体是教师个人
2. 自觉性：是教师个人自觉进行的。
3. 内在性：是教师个人真正从内心深处相信并接受的
4. 实践性：是以教师职业活动和交往的实践为基础。

### 教师职业道德的范畴

1. 教师义务
2. 教师良心
3. 教师公正
4. 教师威信
5. 教师荣誉
6. 教师幸福。

### 教师义务

指教师`对于学生集体或社会应当做的事情`。分为道德义务和非道德义务，道德义务是指能够做出善恶判断的义务，非道德义务是那些不具有道德义务意义的义务。道德义务与非道德义务相比具有一些明显特征，
1. **精神性**：道德行为从本质上来说是不要求回报的，`利他性行为`
2. **自觉性**：道德义务是一种道德主体自觉意识到的道德责任，教师职业义务是教师`自觉自愿履行的义务`
3. **意志特征**即实践特征，道德行为的实施和道德义务的履行`需要主体的道德意志`，同时义务的利他性也决定了履行义务的意志性。

### 教师良心的特点
1. 内在性：是`隐藏在教师内心深处`的一种意识
2. 综合性：是一个`统一的综合整体`。包含着对行为、是非善恶的认识，又包含着责任感、同情感、羞耻感等，还包含着坚强的道德意志
3. 稳定性：良心是以一定的道德信念为基础的，一旦形成就会`比较持久稳定的对人们的行为发挥作用`
4. 广泛性：它渗透着教师的`整个教学活动和教师生活的一切领域之中`。

### 教师公正

教师公正必须具备三个特征
1. 对等性.要对人对事要`一视同仁`
2. 可互换性。是对等性的要求和保证
3. 最终价值判定的可依赖性

教师公正具有以下特点
1. 教育性，这是教师公正的首要特点，`公正行为的教育示范性`以及公正调整的人际关系，主要是师生关系或以师生关系为基础，体现教师自己的教育活动之中
2. 主体的自觉性：重要标志是教师对于自己知道的及其重要性的了解
3. 实施的实质性：教师公正具有相当大的灵活性，`着眼于实际或实质意义上的公正`，并不限定在形式上的公正。

### 教师威信包含五种影响力
1. **专长力量**：即教师的`知识和技能水平`
2. **吸引力量**：是教师在`与他人的关系中`影响作用和亲密性
3. **法统力量**：主要跟`权利和法规有关`的影响力量
4. **奖赏力量**：主要指`对他人可以奖赏的能力`
5. **强制力量**：主要是指`对他人可以惩罚的力量`。

### 教师荣誉

在客观方面，它是`社会的客观评价`，在主观方面，它是`教师个人的道德自我意识`。

### 教师幸福

教师幸福是教育工作者由于感受到理解到`教育目标和教育理想的实现而获得得到精神上的满足体验`。

教师职业道德品质的构成包括教师的`道德认识、道德情感、道德意志、道德信念、道德行为、道德习惯`。

**教师道德认识**包括认识教师道德关系、教师道德原则和规范、教育教学的规律。

**教师道德情感**是基于一定的道德认识基础之上的，教师在道德实践活动中体验并形成的`以爱为基本特征`的道德情感，教师道德情感是构成道德品质的重要方面。

**教师道德意志**是在职业道德活动中表现出来的`克服困难，战胜挫折，超越自我`的坚韧毅力和精神。

**教师道德信念**是教师`对于自身职业责任和义务的真诚信仰`，是教师对于教育事业的深刻认识，强烈情感，顽强意志的统一，在教师道德品质中`处于主导地位`

**教师道德行为**是教师在一定的道德认识，情感意志支配下采取的具有`直观现实性的行动`，`衡量一个教师品质优劣，道德水平高低的客观标志`。教师道德行为选择的标准有以下几种，第一，确定性和不确定性，第二，主观性和客观性，第三，功利性和超功利性。

**教师道德习惯**，是在道德行为反复实践中形成的，具有道德意识，道德行为的直接高度统一，面对具体的道德选择，教师可以`率性而择，完全出于内心的自觉`。

### 教师职业道德实践中常见的错误
1. 物欲性错误，就是`不惜切满足物欲`所导致的错误，包括乱收费，向学生及其家长直接或变相索要财物或方便
2. 权欲性错误，因`权欲过度`而产生的错误，实施不恰当的体罚心理惩罚
3. 名誉性错误，`对名誉的过度追求`，追求虚荣，偷窃别人的成果
4. 情欲性错误，`不择手段的满足一个人的情感需求`，对学生的偏爱，同行之间的嫉妒。
