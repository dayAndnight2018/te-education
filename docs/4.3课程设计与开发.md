# 4.3课程设计与开发

### 什么是课程设计

制定课程目标、选择与组织课程内容、预设学习活动方式的活动，是对课程目标、教育经验、预设活动方式的具体化行为。


### 什么是课程开发

是通过需求分析，确定课程目标，选择教学内容、教学活动，进行计划、组织、实施、评价、修订，最终达到课程目标的整个工作过程。


### 课程开发的模式

#### 泰勒——目标模式

以`目标为中心`，围绕课程目标的确定、实现、评价各个环节进行课程开发。代表人物泰勒，其于1949年出版《课程与教学的基本原理》，被誉为`现代课程理论的圣经`。

1. 学校应该追求哪些目标？
2. 怎么样选择形成学习经验？
3. 怎么样有效组织学习经验？
4. 如何确定这些目标正在得以实现？


主要包括`目标、内容、方法、评价`四个部分。



#### 斯腾豪斯——过程模式

课程的开发是一个`连续不断的研究过程`，`贯穿着对整个过程的评价与修正`。这些集中在课堂实践中，`教师是核心人物`。


### 课程目标

课程目标是`课程本身要实现的具体目标和意图`，通过学习后，能够在德智体等方面期望实现的程度，是最关键的准则。


#### 确定课程目标的依据

1. 学生的需要，这是根本依据
2. 当代社会生活的需要
3. 学科知识及其发展。


### 课程内容

按照一定的逻辑组织编排的`直接经验与间接经验`的总和。

课程内容基本性质就是知识，分为直接经验和间接经验，直接经验就是直接相关的社会知识，自然知识与技能。间接经验就是系统化、理论化的书本知识，`在课程内容中，间接经验为主`。


### 制约课程内容的因素

1. 社会因素，社会发展对学生素质的要求。
2. 受教育者身心发展规律
3. 科学文化知识。科学文化知识本身的特点及发展趋势。


### 课程的文本形式

包括`课程计划、课程标准、教材`

课程计划是规定科目设置、学科顺序、课时分配、学年编制、学周安排。开设什么科目是中心问题。`课程计划是组织教育教学活动的重要依据`。

课程标准是以纲要规定课程的性质与价值、目标与内容、教学实施建议、课程资源开发等指导性文件。`课程标准是编写教科书、组织教学的直接依据，是衡量教学质量的重要标准`

教材就是教科书。编写要求：
1. 科学性与思想性相统一
2. 强调内容的基础性和适用性
3. 知识内在逻辑与教学法统一
4. 理论与实践统一
5. 教科书的编排形式要有助于学习（螺旋式、直线式）
6. 注意与其他学科的联系


### 课程内容组织形式

#### 直线式与螺旋式

直线式前后内容不重复，直线前进。螺旋式则会出现重复，逐渐扩大知识面，加深知识深度，层层递进。

#### 纵向组织、横向组织

纵向：由已知到未知，由简单到复杂

横向：打破学科界限，各学科联系起来。


#### 逻辑顺序、心理顺序

逻辑：按照学科知识本身的内在联系组织

心理：按照学生心理发展特点组织


### 课程实施

忠实取向：`不折不扣地执行`

相互适应取向：执行过程中`相互适应与调整`

课程创生：在具体的`教学情境中创生出教育经验`


### 课程评价

目标评价：以`目标为中心`，看是否达成目标。代表人物`泰勒`

目的游离：从预期目标到`实际结果`上。代表人物`斯克里文`

CIPP模式：评价的目的不在于证明，而在于改进。四流程：`背景评价、输入评价、过程评价、成果评价`。代表人物`斯塔夫比姆`

CSE：形成性评价与综合性评价整合的`动态评价模式`，加利福尼亚大学


### 影响课程开发的主要因素

1. 儿童的成熟、心理特征、兴趣、需要
2. 社会生产力发展、社会制度与政策、社会结构
3. 学科特征
4. 社会文化传统
