# 5.2教学过程

教师根据一定的社会要求、学生的身心发展特点，通过有目的、有计划地指导学生掌握知识与技能、发展智力与体力，培养良好品德和个性，形成科学世界观的过程。


### 教学过程的本质

一、 认识-发展说
    
教学过程`不仅是认识世界的过程，也是学生身心全面发展的过程`。强调学生的主观能动性，但忽略了教师的主导作用

二、 认识-实践说

对人类`已有社会经验的认识，和改造客观世界的实践活动`的统一过程。

三、交往说

教学过程是教师与学生`以课堂为主渠道的交往过程`。



### 教学过程的本质特征

1. 间接性。间接认识客观世界，以间接经验为主。
2. 引导性。学生的认识活动是在教师的引导下完成的
3. 简捷性。教学过程中，学生在很短时间内掌握经过数百年总结的知识。


### 教学过程的基本规律

一、 直接经验与间接经验相结合
1. 以学习`间接经验为主`
2. 学习间接经验要`以直接经验为基础`
3. 防止两种倾向，片面强调书本或实践

二、掌握知识和发展能力相统一

1. `掌握知识是基础`
2. `能力发展是掌握知识的重要条件`
3. 掌握知识和发展能力可以相互转化
4. 防止两种倾向

**形式教育论**：`洛克、裴斯泰洛齐`。主要发展`智力`。

**实质教育论**：`斯宾塞、赫尔巴特`。主要`传授有用的知识`。

三、教师主导和学生主体相统一

1. 充分发挥教师的主导作用；充分发挥学生的主体性和主动性
2. 二者是辩证统一的

教师决定学生的学习方向、内容、进程、结果、质量，起着引导、规范、评价、纠正的作用；对学习方式、学习态度发挥作用；影响学生个性、人生观、世界观的形成

四、传授知识与思想品德教育统一

1. `知识是思想品德形成的基础`
2. 思想品德修养水平的提高为学生积极学习知识`提供动力`
3. 贯彻传授知识与思想品得相统一的规律，要防止两种倾向：脱离知识进行思想品德教育；只强调知识，忽视思想品德教育。


### 教学过程的阶段

1. 激发学习动机
2. 领会知识
3. 巩固知识
4. 运用知识
5. 检查知识
