# 8.4中学生意志发展

意志是人能够自觉地确定目的，有意识的`根据目的动机调节支配行动，努力克服困难，实现目标的心理过程`

意志行动是人特有的自觉确定目的的行动，这是意志的首要特征

克服内部外部的困难是最重要的特征

意志行动以随意动作为基础。

### 动机冲突

意志行动中的动机冲突。人的意志行为是有一定的动机引起的，但是由于动机过度到行为的过程是不同的，当个体的动机相互矛盾时，个体就需要对各种动机权衡轻重做出取舍，动机斗争又称为动机冲突，分为`双趋、双避、趋避、多重趋避冲突`四种

双趋就是对于两个同时都很喜爱的两个事物精选的其一

双避就是希望回避的两种事物，必须取其一

趋避，就是对同一目的兼具好恶

多重趋避就是含有吸引和排斥两种力量的多种目标予以选择时所产生的冲突。


### 意志的品质

1. 意识具有自觉性，一个人能够清晰的认识到自己行动的目的和意义，并能更能主动的支配自己的行动，使之符合既定目标的意志品质
2. 果断性，一个人善于明辨是非，抓住时机，迅速合理的采取行动并执行决定
3. 自制性，一个人善于控制支配自己的情绪
4. 坚韧性，一个人在行动中坚持决定，百折不挠的克服种种困难来达到行动的目的


### 良好意志品质的培养

1. 加强生活的目的性教育，培养学生行为的目的性
2. 加强养成教育，培养自制能力
3. 组织实践活动，在实践中锻炼意志
4. 教会学生正确的对待挫折
5. 根据学生意志品质差异采取不同的措施
6. 发挥教师班集体榜样的模范作用
7. 加强自我的锻炼，从点滴小事做起。
