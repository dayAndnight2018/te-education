# 10.4德育过程

德育过程本质上说就是个体社会化，社会规范，个体化的统一过程

### 德育过程与品德形成过程的关系

德育过程的最终目标是使教育者形成一定的思想品德，品德形成属于人的发展过程

德育过程是对品德形成和发展过程的调节控制，德育具有遵循人的品德形成发展规律，才能有效的促进人的品德形成发展。

德育过程和品德形成的过程的区别，从活动方式上来看，德育过程主要是教育者，受教育者的一个双边活动，而品德形成是学生个体品德自我发展过程，从影响因素上来看，德育过程中中学生主要接受有计划，有目的，有组织的教育影响，而品德形成受各种因素影响，从形成结果来看，德育过程的结果是有意识的培养学生，形成符合社会要求的思想品德，而品德形成过程，结果可能与社会要求一致，也有可能不一致。

### 德育过程的构成要素

教育者，受教育者，德育内容，德育方法

### 德育过程的矛盾

德育过程的基本矛盾是社会通过教师向受教育者提出的`思想道德要求`与`受教育者已有品德水平`之间的矛盾，这是德育过程最一般，最普遍的矛盾，

而社会通过教师向受教育者提出的道德要求，引起受教育者`新的思想道要需要与受教育者原有的品德水平`之间的矛盾，是受教育者品德发展的内部矛盾。

### 德育过程的基本规律

1. 德育过程是具有多种开端的对学生知，情，意，行的培养提高过程。
2. 是组织学生活动与交往统一多方面的教育影响的过程。
3. 德育过程是一个促进学生思想内部矛盾斗争的发展过程，是教育与自我教育相结合的过程
4. 这个过程是一个长期的，反复的，逐步提高的过程。

德育过程一般以知为开端，以行为终结，但由于社会生活的复杂性，德育影响的多种因素，德育具体实施过程中具有多种开端，既可以从提高道德认识开始，即晓之以理，也可以从陶冶刀的情感开始记，动之以情，有时候还能从磨练意志和训练行为开始，即持之以恒，道德教育的开端可不拘于一格，需要具体问题具体分析，根据学生道德品德的具体情况选择适当的开端，最后大道是学生在知情意行几方面和谐发展的目的。
