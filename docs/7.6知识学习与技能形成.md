# 7.6知识学习与技能形成

### 知识的分类

`陈述性知识`：个人能用言语进行直接陈述的知识

`程序性知识`：关于操作步骤的知识

`感性知识`：对活动的外部特征，外部联系一个反映，可分为感知，表象两种水平

`理性知识`：反映的是活动的本质和内在的联系，分为概念和命题两种形式

`策略性知识`：美国心理学家梅耶提出了一种策略性知识，它是关于如何学习如何思维的一个知识

### 知识学习的类型

`符号学习`：又称为表征学习，学习单个符号或者一组符号的意义，符号学习的主要内容是词汇学习。

`概念学习`：是掌握概念的一般意义，实质是掌握一类事物的共同的本质的属性和关键特征，

`命题学习`：是获得有几个概念构成的命题的复合意义，实际上是学习表示若干概念之间关系的判断


`下位学习`：又称为类属学习，把一个新的观念归属于认知结构中原有观念的某一部分，使之相互联系

`上位学习`：是总括学习，是学生掌握一个比认知结构中原有概念的概括和包容程度更高的概念或者命题是产生的。

`并列结合学习`：又称为组合学习，在新命题和认知结构中原有的命题既非下位又非上位，是一种并列的关系产生。


### 知识学习的过程

1. 知识的获得
2. 知识的保持
3. 知识的应用

知识的获得包括知识的`感知和理解`两个过程。一般是通过`知识直观和知识概括`两种形式实现的，知识直观是指主体通过直接感知到的教学材料的表层意义，表面特征进行加工，形成有关事物具体的，特殊的，感性的认识的加工过程，在实际教学过程中，主要有三种直观，一个是实物直观，一个是模象直观，一个是言语直观。

实物直观：实际事物的感性材料

模象直观：包括图片，图表，幻灯片，电影，录像，电视等等

言语直观：在言语的作用下唤起学生头脑中的表象，提供感性材料的直观方式

### 如何提高知识直观的效果？

1. 灵活选用实物直观和模象直观
2. 加强词和形象的配合
3. 运用感知规律，突出直观对象的特点
4. 培养学生的观察能力
5. 让学生充分参与直观过程。


### 知识的概括

主体通过对感性材料的分析，综合，比较，抽象概括等深度加工的改造，获得对一类事物的本质特征及内在联系的，抽象的，一般的，理性的认识的活动

### 有效进行知识概括的策略？

1. 配合运用正例和反例
2. 运用变式
3. 科学的进行比较
4. 激发学生进行自觉的概括。

### 知识的保持

记忆是一个结构性的信息加工系统，由瞬时记忆，短时记忆，长时记忆组成，信息首先进入瞬时记忆，那些引起个体注意的感觉信息才会进入短时记忆，在短时记忆中存储的信息经过加工，在存储入长时记忆中，那么这些保存在长时记忆中的信息在需要时就会被提取到短时记忆中


### 如何运用记忆规律促进知识的保持呢？

1. 明确记忆的目的，增强学习的主动性
2. 理解学习材料的意义，建立知识之间的内在联系
3. 对学习材料进行精细加工，促进理解
4. 运用组块化学习策略，合理组织学习材料
5. 运用多重信息编码方式提高信息加工处理的质量
6. 重视复习方法，防止知识遗忘。


### 技能

技能是指在练习的基础上形成的，按照某些规则或操作程序`顺利完成某种任务的能力`，那么强调技能是一种习得的能力，实际上是一套办事规则

`动作技能`：又称为运动技能操作技能，它是通过学习而形成的合乎规则的`操作活动方式`

`心智技能`：称为智力技能或者认知技能，通过学习而形成的合乎规则的`心智活动方式`。


### 动作技能的形成与培养

冯忠良的四阶段模型：

1. 操作定向是指了解操作活动的结构和要求，在头脑中建立起操作活动的定向映像
2. 操作模仿模仿的实质就是将头脑中形成的定向映像以外显的实际动作表现出来。
3. 操作整合，整合是指把构成整体的各动作要素根据其内在的联系连接成整体，形成操作活动的一个顺序序列。
4. 操作熟练，这是动作技能掌握的一个高级阶段，通过动作练习形成的活动方式对各种变化的条件具有高度的适应性，动作的执行达到高度的程序化，自动化，完善化。

菲茨与波斯纳的三阶段模型：
1. 认知阶段，主要是对所学的动作进行初步认识
2. 连接阶段主要是通过反复练习，使个别动作联系起来
3. 自动化阶段，是将各个动作联合为一个有机的系统，一旦巩固下来，各个动作之间相互协调，就能按照顺序以连锁反应的方式出现并达到自
动化

### 动作技能的培养要求

1. 准确的示范和讲解
2. 必要的适当的训练
3. 充分有效的反馈
4. 建立稳定清晰的动觉。

### 心智技能的形成与培养

冯忠良的三阶段理论：
1. 原型定向，即了解了解原型的活动结构，从而使主体明确活动的方向
2. 原型操作根据智力技能的实践模式，把学生在头脑中已经建立起来的活动程序计划以外显的操作方式付诸实施
3. 原型内化是指智力活动的实践模式，在头脑中进行内部转化

加里培林的五阶段理论：
1. 活动的定向阶段，所谓定向就是使学生了解熟悉活动对象，使他们知道做什么和怎么做，从而使学生在头脑中形成关于心智活动和活动结果的表象，以便对于活动本身及其结果进行定向。
2. 物质和物质化阶段，物质活动是指运用实物进行活动，物质化活动是指运用实物的模型图片，示意图进行活动。
3. 出生的外部言语动作阶段即活动离开了他的物质或物质化的课题，你出生的外部言语形式来完成实在的活动，
4. 不出声的外部言语动作阶段，它是以词的声音表象，动觉表象为支柱进行智力活动的阶段。
5. 内部言语动作阶段，本阶段的主要特点是智力活动压缩，自动化很少发生错误

### 对于心智技能的培养要求

1. 确立合理的智力活动原型
2. 有效的进行分阶段练习
3. 知识影响技能的形成，教师应该了解学生的知识基础，并为学生提供相关知识
4. 注重培养学生认真思考的习惯和独立思考的能力。
