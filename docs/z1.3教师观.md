# z1.3教师观

教师是履行教育教学职责的专业人员，承担教书育人，培养社会主义事业建设者，接班人，提高民族素质的使命，教师工作的本质是`塑造灵魂，塑造生命，塑造人`。

### 教师劳动的特点

1. **复杂性**。
    a. 教师的劳动属于`专业行为`，是一种高度复杂的心智劳动
    b. `劳动对象的复杂性`，劳动对象是千差万别的人，
    c. 劳动`任务的复杂性`不仅要传授文化知识，锻炼技能，还要发展智力培养能力，还培养思想品德，身心健康发展。
    d. 劳动`过程的复杂性`。是一个长期的过程。
    e. 劳动`手段的复杂性`。需要优化组合，各种影响，使之发挥最佳合力。

2. **创造性**。主要表现在第一，`因材施教`，教师必须灵活的针对每一个学生的特点提出不同的要求，第二，`教学方法上不断更新`教学，有法教无定法，第三，教师`需要教育机智`，教育机智就是教师能够根据学生新的，特别的意外的情况，迅速正确地做出判断，随机应变，采取及时，恰当，有效的教育措施解决问题的能力。

3. **主体性和示范性**，主体性是教师自身可以成为活生生的教育因素和具有影响力的榜样，示范性是指教师的言行举止都会成为学生学习的对象。

4. **延续性和广延性**。劳动时间的延续性是教师`没有固定的工作时间长度`，除了正常的工作时间还要利用晚上和休息时间来思考，备课，批改作业等等，广延性是教师不能只在课内校内发挥他们的影响力，还`要走出校门进行家访，协调学校，社会，家庭的教育影响`，达到更好的教育目的。

5. **长期性和间接性**，长期性是`人才培养的周期比较长`，教育影响具有滞后性，间接性是指教师的劳动`不直接创造物质财富`，而是以学生为中介实现价值。

### 教师的职业素养
1. **道德素养**，对待事业要忠于人民的教育事业，对待学生要热爱学生，对待对待集体，要有团结协作精神，对待自己，要以身作则，为人师表
2. **知识素养**，包括政治理论素养，学科专业知识，科学文化知识，教育科学知识，实践性知识。
3. **能力素养**包括语言表达能力，组织教育教学能力，组织管理能力，自我调控与反思的能力。教育科研能力，学习能力，观察学生的能力，创新能力，运用现代教育技术的手段的能力。
4. **心理素养**，一个优秀的教师需要具备良好的心理素质，包括高尚的师德，愉悦的情感，良好的人际关系，健康的人格。

新课程倡导的教师观，教师观就是关于教师职业的基本观念，人们对于教师职业的看法，认识期望的反应。

### 现代教师角色转变⭐️⭐️
1. 从教师与学生的关系来看，教师是`学生学习的促进者`，具体教师是学生学习能力的培养者，教师是学生人生的引路人。
2. 从教学和研究的关系上来看，教师是`教育教学的研究者`
3. 从教学与课程的关系来看，教师是`课程的开发者和建设者`
4. 从学校和社区的关系来看，教师是`社区型开放的教师`。

### 现代教师教育教学行为的转变⭐️⭐️
1. 在对待师生关系上强调`尊重，赞赏`。尊重学生同时意味着不伤害学生的自尊心，要努力做到不体罚学生，不辱骂学生，不大声训斥学生，不冷落学生，不羞辱嘲笑学生，不随意当众批评学生。教师不仅要尊重学生，还要学会发现学生的闪光点，学会赞赏学生
2. 在对待教学关系上，特别强调的是`帮助和引导`。
3. 在对待自我上强调`反思`
4. 在对待与其他教育者的关系上强调`合作`。

### 教师专业发展的内容包括
1. 专业理想。教师的专业精神和教师的专业理想同意是指教师作为教育专业人员所具备的教育理念，乐业，敬业以及努力奉献的精神，
    a. 对于教育事业的忠诚，热爱和奉献
    b. 对于专业理想永无止境的追求
    c. 对专业道德规范和行为准则的自觉遵守
2. 专业知识，专业知识是教师在示范教育和实践中获得的直接作用于教育过程的实用性知识
3. 专业能力，专业能力是教师组织教育活动对于学生有目的施加影响力的能力。它是评价教师的专业水平的核心因素
4. 专业自我，教师的专业自我是指教师在职业生活中创造并体现符合自己的志趣，能力，个性的独特的教育教学生活方式，以及在自身的职业生活中形成的知识观念，价值体系就是风格的总和。

### 教师专业发展的要求⭐️⭐️
1. 要`善于学习`，培养终身学习的意识和能力
2. 要`恒于研究`，成为教育教学的研究者
3. 要`勤于反思`，培养发展自己的反思能力
4. 要`勇于实践`，培养创新精神，实践能力
5. 要`重视教师合作`交往的能力的培养
6. 教师要`成为课程的开发者`。

### 教师专业发展的途径
1. `观摩分析优秀教师的教学活动`
2. 开展`微格教育`，微格教育是指以少数学生为对象，较短时间内5~20分钟做小型的课堂教学，并把教学过程设置成录像课后再进行分析
3. 进行`专业训练`。将有效的教学策略交给新教师，其中的关键程序有，第一，每天进行回顾，第二，有意义地呈现新材料，第三，有效的指导课堂作业，第四，布置家庭作业，第五，每周，每月都进行回顾
4. 进行`教学反思`。布鲁巴奇等人提出了四种反思方法，一，反思日记，二，详细描述，第三，交流讨论，第四，行动研究，美国教育心理学家波斯纳也提出了教师成长的公式，经验加反思等于成长。

### 福勒和布朗的教师专业发展三阶段理论
1. `关注生存`是指教师一开始非常关注自己的生存适应性，把大量的时间花在如何跟学生搞好个人关系上，想法控制学生，
2. `关注情景`是关注如何教好每一堂课以及班级大小，时间压力，备课材料是否充分等
3. `关注学生`，考虑学生的个别差异，认识到不同发展水平的学生有不同的需要，根据学生的差异采取适当的教学，促进学生发展。


### 叶澜自我更新的取向教师专业发展五阶段理论
1. `非关注阶段`，这一阶段的个体无意识中以非教师职业定向的形式形成了较稳固的教育信念，具备了一些直觉式的前科学知识以及与教师专业能力密切相关的一般能力。
2. `虚拟关注阶段`，一般是师范学习阶段的学生或实习期的教师，他们对于合格教师的要求开始思考，在虚拟的教育环境中获得某些经验，对教育理论及教师技能进行学习和训练，有了对于自我专业发展反思的萌萌芽
3. `生存关注`阶段通常是新任教师在现实的冲击下产生了强烈的自我专业发展的忧患意识，特别是关注专业活动中的生存技能。
4. `任务关注`阶段，随着教育教学基本的生存知识技能的掌握，自信心日益增强，从关注生存转移到更多关注教学，
5. `自我更新关注`阶段，教师不再受外部评价和职业升迁的牵制，自觉依照教师发展的一般路线和自己目前的发展条件，有意识的自我规划，谋求最大程度的自我发展，关注学生的整体发展，积累了比较科学的个人实践知识。


### 斯德菲的教师专业发展五阶段理论

1. `预备生涯`阶段。主要为新任职的教师或重新任职的教师具有理想主义，有活力，富有创意，努力努力接纳新观念，积极进取，努力向上的特点
2. `专家生涯`阶段。具有较高的教学水平技巧，较高的透视能力，能够随时掌握学生动态，对学生有较高的期望值，能够激发自我潜能，达到自我实现
3. `退缩生涯`阶段。出现倦怠感
4. `更新生涯`阶段，此阶段在开始出现厌烦的征兆时，采取积极的应对措施，主动致力于吸纳新知识，重新振奋起来，重新回到追求专业成长的一个状态
5. `退出生涯`阶段，到了退休年龄或其他原因离开教学岗位。


### 伯利纳的教师专业发展五阶段理论

1. `新手教师`阶段。对于刚刚从事教学工作的教师，这个阶段主要需求是了解与教学相关的实际情况，熟悉具体的教学情境，积累教学经验
2. `熟练的新手教师`阶段。经过2~3年，新手教师逐渐发展成为熟练的新手教师。在教学过程中积累了一些经验，意识到了教学情景的相似性，把过去所学知识与现在所有的情景问题相结合，也会运用一些教学策略来调节控制自己的行为
3. `胜任型的教师`的阶段。大部分熟练新手教师经过三四年的教学实践和职业培训后，成为胜任型的教师，这是教师发展的基本的目标，能够按照个人的想法自由处理事件，依据自己的计划对所选的信息并做出反应，能够对所做的事情承担更多的职责。
4. `业务精干型教师`阶段，经过5年左右的知识和经验积累，有相当部分的胜任型表示成为业务精干型。他们能从积累的经验中综合识别出情景的相似性，从截然不同的事件中考虑到事物的相互联系。
5. `专家型的教师`阶段，这是最终阶段。不但有直觉的把握，而且能以非分析性，非随意性的方式理智的做出合适的反应，其行为表现流畅灵活，不需要刻意加工。
