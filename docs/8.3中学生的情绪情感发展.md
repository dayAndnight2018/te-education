# 8.3中学生的情绪情感发展

`认知`是情绪情感产生的基础，`需要`是引发情绪情感的中介，不同的态度体验反映着客观事物与人的需要之间的不同关系。


### 情绪的分类

人的基本情绪分为`喜怒哀惧`。

根据情绪发生的强度，持续性和紧张程度的不同，分为三种：

1. **心境**是一种`微弱的，持续时间较长`的带有`弥漫性的情绪状态`，心境是整个人的状态
2. **激情**是一种`爆发式`猛烈、持续时间短暂的情绪状态，它往往带有`特定的指向性和较为明显的外部行为`表现
3. **应激**是由`出乎意料的紧迫情况`所引发的急速而高度紧张的情绪状态，人们遇到`突发状况或意外发生危险`的时候，为了应付瞬息万变的紧急状况，迅速的做出反应。

### 情感的分类

从情感的社会内容角度来看，人类的情感有`道德感，美感和理智感`三种
1. 道德感就是根据一定的`道德标准`评价人的思想，意图和言行时产生的主观体验
2. 美感是根据一定的`审美标准`对自然或社会及其艺术上的表现评价时所产生的情感体验
3. 理智感就是人`认识事物和探索真理的需要是否得到满足`而产生的一种主观体验。

### 詹姆士-朗格理论

情绪的产生是`植物性神经系统活动的产物`，詹姆斯认为情绪是对身体变化的知觉，人们由于哭泣而悲伤，由于打斗而愤怒，狼格则认为情绪是内脏活动的结果，二人的观点基本一致，即情绪刺激引起身体的生理反应，而生理反应进一步导致情绪体验的产生。

### 坎农巴德学说

坎农巴德认为情绪的中枢在`中枢神经系统的丘脑`，外界刺激引起感觉器官的神经冲动传至丘脑，再由丘脑同时向大脑和植物性神经系统发出神经冲动，从而在大脑产生情绪的主观体验，而有植物性神经系统产生个体的生理变化。

### 阿诺德的评定兴奋情绪学说

阿诺德认为，刺激情景并不直接决定情绪的性质，从刺激出现到情绪产生，需要`经过对刺激的评估和评价`。评估不同，会产生不同的情绪反应，情绪的产生是大脑皮层和皮下组织协同活动的结果，大脑皮层的兴奋是情绪行为的最重要条件，感受器接受情绪刺激产生神经冲动，通过内导神经经倾倒传到大脑皮层，刺激情景在此得到评估，形成一种特殊的态度，这种态度通过外导神经将皮层的神经冲动传到丘脑的交感神经，将兴奋发到血管和内脏产生的变化使其获得感觉。

### 沙赫特和辛格的情绪理论

他们认为对于特定的情绪来说，有三个必不可少的因素，

1. 体验到`高度的生理唤醒`，如心率加快，手出汗，呼吸急促等等
2. 个体`对生理状态的变化进行认知性的唤醒`
3. 相应的`环境因素`，沙特和辛格通过实验结果证明，即使个体处于生理幻想状态，仅是生理状态的单独作用也不能引起人的情绪，同样环境因素也不能单独决定人的情绪，对人的情绪产生起决定作用的是`认知`。

### 拉扎勒斯的认知评价理论

拉扎勒斯认为情绪是`人与环境相互作用的产物`，在情绪过程中，人不仅反映环境中的刺激事件对自己的影响，同时还要调节自己对刺激的反应，也就是说情绪是个体对于环境知觉到有害或者有益的反应，因此情绪活动中人们需要不断的评价刺激事件与自身的关系。

### 认知和情绪之间相互影响

认知在情绪中的作用主要是在于判断，评价刺激物对于个体符合需要的程度，它是个体对刺激物产生肯定或否定态度的决定性因素，认知过程中伴随着情绪体验，感知觉是诱发情绪的首要条件，记忆与想象决定着情绪，思维影响情绪反应的方式和速度，情绪对认知的影响，情绪影响着认知过程的质量和效率，不管何种情绪，只要一经产生，便会影响整个认知过程，是整个认知过程都感染上情绪的色彩，情绪积极时，认知过程也积极，情绪消极时，认知过程也消极情绪对认知的影响主要表现在情绪的动机性功能，信号性功能和感染性功能三个方面。

### 动机-分化理论

有些学者主张情绪具有动机的性质，以`汤姆金斯和伊沙德`为代表，建立了情绪的`动机分化理论`，该理论的主要观点有，
1. 情绪是分化的，存在着不同体验的独立情绪，这些独立情绪具有动机功能
2. 情绪是人格系统的组成部分，是人格系统的核心动力
3. 情绪的分化是进化过程的产物，具有灵活多样的适用功能，且在有机体的适应和生存上起着核心的作用。

### 中学生情绪发展的特点

1. 情绪非常的丰富
2. 情绪反应强烈，易动感情
3. 情绪理解力增强，学会用情绪表达规则
4. 能采用有效的情绪调节手段
5. 情绪的持续性较长，新进化
6. 出现反抗情绪逆反心理
7. 情绪发生变化的两极性
8. 情绪表现的矛盾性。

### 中学生情感发展的特点

1. 自尊心强烈而敏感
2. 情感的社会性加强
3. 理智感，美感和道德感丰富和深化。

### 中学生良好情绪的标准

1. 能够正确反映一定的环境影响，善于准确表达自己的感受
2. 能够对引起情绪的刺激做出适当强度的反应
3. 具备情绪反应的转移能力
4. 良好的情绪应该符合学生的年龄特点。

### 中学生良好情绪的培养方法

1. 正确认识情绪
2. 培养正确的人生观
3. 锻炼身体
4. 使自己永远保持一种乐观向上的情绪基调，培养幽默感
5. 培养高尚的道德情操
6. 培养消除不良情绪的能力。

### 对中学生情绪调节的指导

1. 形成适宜的情绪状态
2. 丰富情绪体验
3. 引导学生正确的看待问题
4. 教会学生情绪调节方法
5. 通过实际锻炼提高学生的情绪劳动调节能力。
