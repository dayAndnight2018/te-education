# 3.2教育制度

### 什么是教育制度

教育制度是一个国家或地区`各级各类教育机构与组织的体系及各项规定`的总和。

广义：`国民教育制度`，关于教育设施及有关规章制度的总和

狭义：`学校教育制度`，简称学制。是各级各类学校的总体系，规定学校的性质、任务、要求、入学条件、修业年限及之间的关系。


### 教育制度的特征

客观性：不以人的意志为转移，具有客观基础和发展规律

规范性：任何教育制度都是根据规定者的需要制定的，具有规范性，体现在入学条件、培养目标的确定上

历史性：随着时间变化，教育制度发生变化

强制性：教育制度对个体有一定的强制作用，要求无条件遵守


### 学制建立的依据

1. 生产力发展水平、科技发展
2. 社会政治经济制度
3. 青少年儿童身心健康发展规律
4. 人口发展状况
5. 文化传统
6. 本国学制的发展，国外学制的影响


### 现代学制的分类

双轨制：英法德国，分为学术教育和职业教育

单轨制：美国，从小学到大学，形式上任何儿童都可以入学

分支型：苏联，小学初中是单轨，之后开始分流，一部分继续普通教育，一部分接受职业教育。（我国）


### 我国学制

从清末，废科举，兴学堂开始

壬寅学制《钦定学堂章程》：参考日本学制，近代教育史上最高国家正式颁布的学制，但未实行。

癸卯学制《奏定学堂章程》：参考日本学制，第一部被国家正式颁布并实施的学制。中学为体、西学为用

壬子癸丑学制：参考日本学制，第一个具有资本主义性质的学制，法律上教育机会均等，第一次规定男女同校，充实了自然学科的内容，学堂改为学校

壬戌学制：参考美国学制，第一次按照学龄儿童的身心发展规律划分阶段，采用633分段法


### 现行学制的结构

层次上：学前教育、初等教育、中等教育、高等教育

类别上：基础教育、职业技术教育、高等教育、成人教育、特殊教育


### 普通中学的任务

1. 为国家培养合格的劳动后备力量，满足社会主义建设的需要
2. 为高一级学校输送合格的新生，满足国家对高级人才的需要


### 义务教育制度

适龄儿童必须接受的教育

强制性：国家强制力保证实施

普及性：全体适龄儿童必须接受教育

免费性

公共性：社会公共事业

基础性：基础教育，提高国民素质


### 当代发达国家学制改革的趋势

1. 加强学前教育，重视与小学的衔接
2. 普及义务教育，延迟义务教育年限
3. 普通教育与职业教育渗透发展
4. 高等教育普及化
5. 终身教育体系日趋完善
6. 教育社会化和社会教育化
7. 教育国际交流加强
8. 学历教育与非学历教育界限逐渐淡化
