# 9.3压力与挫折

压力是个体面对具有威胁性的刺激情景时候，伴有躯体机能和心理活动改变的一种身心紧张状态，也成为应激状态

### 压力来源

来源主要有以下四种，

躯体性的压力源

心理性的压力源

社会性的压力源

文化性的压力源。

### 挫折

挫折是个体在从事有目的的活动过程中遇到障碍、干扰，这是个人动机不能实现，需要不能满足的一个情绪状态，主要应对措施有
1. 升华：指心理欲望从社会不可接受的方向转向社会可接受的方向
2. 补偿：一个人所追求的目标理想受到挫折，由于本身的某种缺陷达不到你用另一种目标来代替，或者通过另一种活动来弥补，从而减轻心理上的不适。
3. 投射：是指自我将不能接受的冲动与往观念归因于客观和别人，这对于婴儿是正常，对于成年人倒是有一点偏执妄想
4. 幽默个体遇到挫折困难或者尴尬时，利用机智双关，比喻，诙谐，自嘲等来化解困难，摆脱内心的失衡状态。
5. 合理宣泄，通过创设一种情景，使受挫者能够自由的抒发受压抑的情绪。
6. 认知重组，对挫折情景重新认识评价
7. 否定对已经发生了令人痛苦的事实加以否定，认为他根本没有发生减轻逃避心理上的痛苦
8. 合理化，合理化是指纹饰作用，个体无法达到的目标和行为，不符合规范，是用有利于自己的理由来辩解秋的解脱，自我安慰。
9. 退行，退行是指退行到前面的发展阶段，指一个人遇到困难的时候放弃，已经学到了比较成熟的应对技巧方式，采用原始幼稚的方式去应对困难，满足自己的欲望。
